# 평가 세트

`cases.jsonl`은 특정 회사나 프로젝트에서 가져오지 않은 공개용 합성 사례 20개입니다. 문제 표현 16개와 정상 또는 반례 4개를 함께 넣어, 단순 금지어 검사가 과잉 지적하는지 확인할 수 있게 했습니다.

각 줄의 필드는 다음과 같습니다.

- `id`: 안정적인 사례 ID
- `source`: 공개 가능 출처. 현재 버전은 모두 `synthetic`
- `category`: 주된 검토 범주
- `text`: 검사할 문장
- `expected`: `통과`, `구체화 필요`, `의미 확인 필요` 중 하나
- `inference`: 독자가 추측해야 하는 정보
- `rewrite`: 허용 가능한 수정안 또는 확인 질문
- `preserve`: 수정 시 보존할 식별자·기술 용어

## 블랙박스 생성 실험

`prompts/`의 세 프롬프트는 모델에 문체 연구 목적을 알리지 않은 채 복잡한 권한·회계·통계 설계를 설명하게 합니다. `raw/`에는 동일 프롬프트를 Claude Sonnet과 Codex gpt-5.4에 적용한 원출력이 있습니다. 실행 환경은 `run-metadata.json`에 기록했습니다.

Gemini CLI 0.28.0과 `gemini-2.5-pro`도 시도했으나 연결된 계정이 제품 라이선스 오류 403을 반환했습니다. 계정 재인증이나 API 과금 활성화는 하지 않았으며 결과를 만들었다고 기록하지 않습니다.

## 검증

```bash
python scripts/validate_evals.py
```

이 명령은 JSONL 형식, 필수 필드, ID 중복, 판정값, 보존 식별자가 수정안에 남았는지 확인합니다. 모델의 한국어 품질을 자동 판정하지는 않습니다.
