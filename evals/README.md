# 평가 세트

`cases.jsonl`은 특정 회사나 프로젝트에서 가져오지 않은 공개용 합성 사례 20개입니다. 문제 표현 16개와 정상 또는 반례 4개를 함께 넣어, 단순 금지어 검사가 과잉 지적하는지 확인할 수 있게 했습니다.

각 줄의 필드는 다음과 같습니다.

- `id`: 안정적인 사례 ID
- `source`: 공개 가능 출처. 현재 버전은 모두 `synthetic`
- `category`: 주된 검토 범주
- `text`: 검사할 문장
- `expected`: `통과`, `구체화 필요`, `의미 확인 필요` 중 하나
- `inference`: 독자가 추측해야 하는 정보
- `rewrite`: 허용 가능한 수정안 또는 확인 질문
- `preserve`: 수정 시 보존할 식별자·기술 용어

## 블랙박스 생성 실험

`prompts/`의 세 프롬프트는 모델에 문체 연구 목적을 알리지 않은 채 복잡한 권한·회계·통계 설계를 설명하게 합니다. `raw/`에는 동일 프롬프트를 Claude Sonnet과 Codex gpt-5.4에 적용한 원출력이 있습니다. 실행 환경은 `run-metadata.json`에 기록했습니다.

Gemini CLI 0.28.0과 `gemini-2.5-pro`도 시도했으나 연결된 계정이 제품 라이선스 오류 403을 반환했습니다. 계정 재인증이나 API 과금 활성화는 하지 않았으며 결과를 만들었다고 기록하지 않습니다.

## CLI 설치·동작 스모크 테스트

[`cli-smoke/`](cli-smoke/README.md)는 공개 GitHub 저장소에서 스킬을 새 프로젝트에 설치하고 Claude Code와 Codex CLI가 이를 발견·적용하는지 확인한 기록입니다. 설치본과 원본 5개 파일의 내용 일치, 세 문장에 대한 기대 행동, CLI별 실제 출력과 테스트 한계를 함께 공개합니다.

이 테스트는 배포 경로와 핵심 행동을 빠르게 확인하기 위한 것입니다. 모델 일반 성능이나 통계적 향상을 주장하는 자료로 사용하지 않습니다.

## 긴 문맥 효과 실험

[`context-effect-v3/`](context-effect-v3/README.md)는 같은 비유 세 문장을 불충분·충분·무관·충돌 문맥에 반복해 넣고, Claude와 Codex의 열 모델에서 현재 스킬 지침의 유무를 비교합니다. 짧은 회귀 문항이 실제 문서의 전후 맥락을 생략한다는 한계를 보완하기 위한 통합 시험입니다.

12개 합성 문맥, 80개 모델 출력, 실행 메타데이터와 자동 선별 점수를 공개합니다. 문맥이 길다는 사실과 뜻을 확정할 근거가 있다는 사실은 구분해 해석합니다.

## 자연스러움 효과 실험

[`naturalness-effect-v4/`](naturalness-effect-v4/README.md)는 뜻을 확정할 수 있는 문맥에서 현재 스킬이 낯선 혼합어, 임의의 비유, 명사 압축, 설명을 대신하는 평가와 음역어를 실제로 고치는지 측정합니다. 의미 확정·보류를 측정한 v3와 달리, 이상 표현 제거를 주목표로 두고 핵심 의미 보존과 정상 문장 보존을 통과 조건으로 함께 봅니다.

10개 모델의 무지침/현재 스킬 조건에서 얻은 20개 원출력과 240개 사례 판정, 엄격 문자열 점수와 형태 차이를 허용한 민감도 점수를 모두 공개합니다. Ollama Cloud의 과거 429도 동시성 1로 재확인했습니다.

## 검증

```bash
python scripts/validate_evals.py
```

이 명령은 JSONL 형식, 필수 필드, ID 중복, 판정값, 보존 식별자가 수정안에 남았는지 확인합니다. CLI 스모크 테스트의 JSON 문법, 사례 ID와 필수 결과 파일도 확인합니다. 모델의 한국어 품질을 자동 판정하지는 않습니다.
