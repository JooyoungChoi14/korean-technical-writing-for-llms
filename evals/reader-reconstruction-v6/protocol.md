# v6 독자 복원 부담 메타 평가 사전 계획

## 질문

v5는 수정문이 문맥의 많은 세부사항을 포함하는지 문자열과 정규식으로 측정했다. 이번 평가는 기존 60개 출력을 다시 생성하지 않고 다음 질문으로 재평가한다.

> 수정문만 읽은 독립 판정 모델이 원래 문제 문장이 전달해야 했던 최소 명제를 복원할 수 있는가?

“더 자연스러운가”라는 선호 판단은 요구하지 않는다. 문장에 주체·동작·대상·조건·결과가 명시돼 있는지만 판정한다.

## 고정할 자료

- 원출력: v5의 현행/후보 조건 60개 출력
- 대상: 각 출력의 이상 표현 사례 12개, 총 720개 수정 결과
- 최소 명제: [`minimum-propositions.json`](minimum-propositions.json)
- 블라인드 순서: 고정 시드 `20260903`

최소 명제는 문맥 전체의 세부사항이 아니라 검토 대상 문장이 독립적으로 전달해야 하는 정보로 제한한다. 결과 생성 전에 명제와 판정 배치를 커밋한다.

## 교차 판정

세 모델을 판정자로 사용한다.

| 판정자 | 지정값 |
|---|---|
| Claude Code | `claude-fable-5` |
| Codex CLI | `gpt-5.6-sol` |
| Ollama Cloud | `kimi-k3` |

한 출력은 같은 계열의 모델에 판정시키지 않는다.

- Claude 출력: Codex와 Ollama가 판정
- Codex 출력: Claude와 Ollama가 판정
- Ollama 출력: Claude와 Codex가 판정

각 수정 결과에는 두 판정이 생긴다. 판정 프롬프트에는 원 생성 모델, 현행/후보 조건, 실행 번호와 기대 결론을 넣지 않는다. 판정자는 수정문과 최소 명제만 보고 각 명제가 문장에 명시돼 있는지 답한다.

## 지표

- **엄격 명제 복원율:** 두 판정자가 모두 명시됐다고 답한 명제의 비율
- **완전 복원율:** 필요한 최소 명제를 두 판정자가 모두 전부 확인한 수정문의 비율
- **주체·동작 명시율:** 두 판정자가 모두 주체와 핵심 동작을 문장만으로 알 수 있다고 답한 비율
- **판정 일치율:** 명제별 참/거짓 판정이 서로 같은 비율
- **관대한 명제 복원율:** 판정자 중 하나 이상이 명시됐다고 답한 비율. 엄격 점수의 민감도 분석으로만 사용

이 지표는 v5의 이상 표현 제거율, 정상 문장 보존율과 함께 해석한다. 판정 모델에는 자연스러움, 선호도나 문장 미학을 묻지 않는다.

## 사전 해석 기준

교차 판정의 명제별 일치율이 80% 미만이면 자동 의미 판정은 불안정하다고 본다. 80% 이상일 때 후보 지침의 메타 평가 신호는 다음 두 조건을 모두 만족해야 한다고 본다.

1. 엄격 명제 복원율이 현행보다 5%p 이상 높다.
2. 완전 복원율이 현행보다 3%p 이상 높다.

이는 v5의 사전 `hold` 결정을 소급 변경하는 채택 기준이 아니다. 문자열 중심 평가와 독자 복원 평가가 같은 방향을 가리키는지 확인하는 기준이다.

## 한계

판정자가 LLM이므로 인간 선호를 대신하지 않는다. 교차 계열과 두 판정자 일치를 사용해 자기 평가와 한 모델의 편향을 줄이지만 없애지는 못한다. 이 결과가 뒷받침하는 주장은 “한국인이 더 자연스럽다고 느낀다”가 아니라 “문장만으로 사전 정의한 최소 명제를 복원할 수 있다”에 한정한다.
