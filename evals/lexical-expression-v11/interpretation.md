# v11 결과 해석

이번에는 같은 원문·같은 진단 절차에서 자연스러운 한국어 요청(N)과 스킬 본문을 추가한 요청(NS)을 실제로 비교했다. 선정된 후보에서 **스킬 추가가 표현 개선에 기여한 정황**을 확보했다. 모든 표현이나 모델에서 효과를 보장한다는 결론은 아니다.

## 확인된 결과

- 10개 요청 모델, 후보 4개와 대조문 2개, 조건별 1회. 실제 호출 238회, 429는 0건이었다. 서비스별 동시 1개와 응답 후 10초 간격을 유지했다. 간격 덕분이라고 인과적으로 입증한 것은 아니다.
- 주 분석은 후보 38쌍과 대조문 18쌍이다. 후보의 핵심 어휘에 대한 현재 작업 Astra 가검토는 NS 우세 19, N 우세 2, 동률 17이었다.
- 우세 출력의 의미 보존까지 통과한 후보는 NS 12쌍, N 2쌍이다. 나머지 NS 우세 7쌍은 의미 보존을 유보했으므로 검증된 개선으로 합치지 않는다.
- 후보 전체 의미 보존 가검토는 N에서 보존 31·유보 7, NS에서 보존 26·유보 11·위험 1이었다. 원문 유지도 보존으로 세므로 이 수치만으로 N의 품질 우세를 뜻하지 않는다. NS가 더 바꾸는 과정에서 의미 확인 부담도 늘어난 것으로 읽을 수 있다.
- 정상 문장 T052는 모든 유효 진단에서 문제없음이었다. 범위 제외 예시 T054는 N에서 문제 7·유보 1·문제없음 2, NS에서 문제 3·문제없음 7이었다. NS의 대조문 수정 하나에는 필요 여부를 실제 변경 상태로 바꿀 의미 위험도 기록했다.

## 이전보다 말할 수 있게 된 것

단순히 고친 사례가 존재하는 수준을 넘어, **이 표본과 작업 흐름에서는 일반 요청보다 스킬 추가 조건의 핵심 어휘가 더 나은 쌍이 많았다.** 반대 사례와 동률도 함께 확보했다. 진단을 먼저 저장했기 때문에 미수정이 미발견인지, 유지 판단인지, 의미를 확정할 수 없어 유보한 것인지도 구분할 수 있다.

GLM 5.2와 GLM 5.3 Flash는 각각 24회 모두 파싱 가능한 응답을 반환했다. GLM 5.3은 24회 중 시간 초과 1건과 JSON 뒤 설명문에 따른 파싱 실패 2건이 있었다. 두 설명문 사례의 JSON 블록을 사후 추출하면 원문을 유지한 유효한 교정문이므로 언어 실패로 세지 않는다. DeepSeek의 2건은 서비스 한도에 의한 생성 미완료였다. 따라서 모델 배제와 호출·수신 문제를 계속 구분해야 한다.

## 아직 입증하지 못한 것

검토자는 실험 맥락을 아는 현재 작업 Astra이며 독립·맹검·사람 평가가 아니다. 같은 후보 4개를 여러 모델에 반복했고, 후보는 사후 선정했으며 일부 어휘와 제외 대조문은 스킬 예시에 이미 들어 있다. 따라서 38쌍을 독립적인 38문항으로 간주하거나 문서 전반의 효과·외부 독자 합의·보지 못한 표현에 대한 일반화로 확대할 수 없다.

실험은 스킬 본문 삽입을 포함한 진단→교정 절차다. 스킬 자동 선택이나 신규 문서 작성 시 예방 효과는 시험하지 않았다. 서비스별 전달 방식도 달라 모델 순위를 정할 근거가 아니다.

이번 결과를 근거로 스킬을 다시 전면 개편하거나 모델을 일괄 제외할 이유는 없다. 현재 버전을 비교 기준으로 보존하고, 다음 검증에서 스킬 예시에 없는 새 어휘와 문맥을 사용하며 독립 평가를 추가하는 편이 타당하다. 의미 유보를 어떻게 처리할지도 표현 자연스러움과 별도 기준으로 유지해야 한다. 이번 실행에서는 추가 모집·공개·재호출을 하지 않았다.
