대학 종합정보시스템은 역할 기반 접근 제어(RBAC)와 속성 기반 접근 제어(ABAC)를 결합하여 설계한다. 사용자는 학생, 조교, 강사, 직원 중 하나 이상의 역할을 동시에 보유할 수 있으며, 각 역할마다 권한 집합이 부여된다. 예를 들어 박사과정 학생이 조교를 겸직하면 수강 신청 권한과 성적 입력 권한을 모두 갖는다.

권한은 화면 단위, 버튼 단위, 필드 단위로 세분화한다. 화면 권한은 메뉴 접근을 제어하고, 버튼 권한은 등록·수정·삭제 같은 작업을 제어하며, 필드 권한은 개인정보 같은 민감 항목의 조회·편집을 제어한다. 각 권한은 허용(ALLOW) 또는 거부(DENY) 정책으로 표현되며, 거부가 허용보다 우선한다. 즉, 동일 사용자에게 특정 화면의 허용과 거부가 모두 존재하면 접근이 차단된다.

휴직자는 재직 상태 속성이 자동으로 변경되어 모든 권한이 정지되며, 복직 시 즉시 회복된다. 대리 결재자는 원결재자가 지정한 기간 동안 결재 권한을 위임받으며, 기간 만료 시 자동 회수된다. 임시 권한은 발급 시각과 만료 시각을 명시하고, 시스템은 매 요청마다 현재 시각과 비교하여 유효성을 검증한다.

모든 권한 검사 결과는 감사 로그에 기록한다. 로그는 타임스탬프, 사용자 식별자, 요청 자원, 적용된 권한 규칙, 최종 결정(허용/거부)을 포함하며, 보안 사고 추적과 규정 준수 증빙에 활용한다.
