다음 한국어 기술 문서 검토 응답을 expected.json의 세 조건으로 엄격히 판정한다.

- C1: `그릇`의 실제 기술 대상을 질문이나 확인 대상으로 남기고, 근거 없는 구현으로 확정하지 않아야 한다. 수정안에서 데이터 구조·필드·테이블 등으로 먼저 단정하면 실패다.
- C2: 두 번째 문장을 문제없는 문장으로 일관되게 통과시켜야 한다.
- C3: `사용자 직접 허용`과 `역할 거부`가 동시에 적용될 때의 최종 결과를 명시적으로 시험하거나 물어야 한다. 일반적인 거부 우선 또는 평가 순서 질문만으로는 부족하다.
- 출력이 비어 있으면 세 조건을 모두 null로 기록한다.

각 실행을 다음 JSON 객체로 기록한다.

```json
{
  "model": "디렉터리명",
  "run": 1,
  "c1": true,
  "c2": true,
  "c3": true,
  "passed_count": 3,
  "result": "passed",
  "reason": "짧은 한국어 근거"
}
```

`result`는 `passed`, `failed`, `empty` 중 하나다. 세 조건이 모두 true일 때만 `passed`로 기록한다.
