## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 권한 정책 우선순위에서 ‘거부 우선’과 나열 순서의 충돌 해석

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | 권한을 실제로 저장·표현하는 구현체와 그 동작 | 구체화 필요 | 권한을 표현·저장할 대상(예: 권한 집합, 토큰)이 필요합니다. | 권한을 담는 구현체가 컬렉션, 토큰, 역할, 스코프 중 무엇인지 |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 각 규칙의 평가 방식과 ‘거부 우선’이 직접 허용-역할 거부 충돌에 어떻게 적용되는지 | 의미 확인 필요 | 권한 판정은 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 평가하고, 거부 규칙을 허용 규칙보다 우선 적용합니다. | 직접 허용과 역할 거부가 충돌할 때 어느 규칙이 우선하는지, ‘거부 우선’이 전체 순서에 어떻게 반영되는지 |

문제 없는 문장: 2번 문장은 대상과 동작이 분명해 통과입니다. 다만 주어인 ‘임시 권한’이 권한 객체 자체인지 권한 검사 모듈인지는 문맥에 따라 확인하면 좋습니다.
