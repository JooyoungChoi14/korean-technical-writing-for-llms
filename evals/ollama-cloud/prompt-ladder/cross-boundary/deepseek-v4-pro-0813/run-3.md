## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 3번의 적용 순서와 ‘거부 우선’ 규칙의 관계가 모순될 수 있음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | ‘그릇’이 실제로 어떤 자료 구조·인터페이스인지, ‘담아낸다’가 저장·표현·전달 중 무엇인지 | 구체화 필요 | 권한 정보를 저장하거나 표현할 구조가 필요합니다. | 권한을 담을 대상이 객체, 목록, 인터페이스 중 무엇인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 나열된 순서가 평가 순서인지, ‘거부 우선’이 같은 수준에서만인지 전체 규칙에서인지, 첫 일치 규칙이 적용되는지 | 의미 확인 필요 | 권한 판정은 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 평가하되, 같은 수준에서는 거부를 허용보다 우선합니다. (잠정) | 사용자 직접 허용이 역할 거부보다 우선하는지, 거부 우선이 모든 수준에 적용되는지, 평가가 첫 일치로 끝나는지 |
