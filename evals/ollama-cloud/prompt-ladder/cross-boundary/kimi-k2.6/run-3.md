## 요약
- 구체화 필요 2건
- 가장 큰 독해 부담: 3번 문장의 평가 순서와 충돌 해결 메커니즘이 압축되어 있어 독자가 정책 상세를 복원해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 어떤 프로그래밍 요소(객체, 변수, 컬렉션 등)를 가리키는지 | 구체화 필요 | 권한을 저장할 [객체/속성/구조]가 필요합니다. | '그릇'이 클래스, 인터페이스, 변수 중 어떤 개념을 지칭하는지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '순으로 적용'이 평가 순서인지 우선순위인지, '거부를 우선'이 충돌 시 deny-override를 의미하는지 | 구체화 필요 | 권한 평가 시 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 규칙을 확인하며, 규칙이 충돌하면 거부를 최종 결정으로 우선합니다. | 이 순서가 평가 순서인지 우선순위인지, '거부를 우선'이 충돌 해결 원칙인지 |
