## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 "그릇"이 가리키는 구현체와 동작이 불분명하여 독자가 비유에서 실제 개념을 복원해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 변수, 객체, 필드, 테이블 중 무엇인지; "담아낸다"는 저장, 보관, 관리 중 어떤 동작인지 | 구체화 필요 | 권한 정보를 저장할 [구체적인 저장소/객체]가 필요합니다. | "그릇"이 가리키는 구현체(클래스, DB 테이블, 설정 파일 등)와 저장할 권한 정보의 범위 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "순으로 적용"이 평가 순서인지 우선순위인지; "거부를 우선"이 충돌 시 어떤 결과를 내는지 | 구체화 필요 | 권한을 평가할 때 다음 우선순위를 적용합니다: 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용. 거부와 허용이 충돌하면 거부를 우선합니다. | "순으로 적용"이 평가 순서인지 우선순위 규칙인지, 충돌 시의 구체적인 처리 방식 |

## 문제 없는 문장
- **2번**: "임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다." — 대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청)이 명확합니다.
