## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 3번 문장의 우선순위 규칙. 4개 항목의 상대적 순서와 "거부를 우선"의 정확한 의미가 불분명합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 어떤 데이터 구조·객체·필드·테이블인지, '담아낸다'가 저장/보관/관리 중 무엇인지 | 구체화 필요 | 권한을 저장할 데이터 구조가 필요합니다. | 실제 사용할 데이터 구조의 이름과 권한에 포함될 속성 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 4개 항목의 전체 우선순위(특히 사용자 설정과 역할 설정의 상대적 우선순위), '거부를 우선'의 정확한 규칙 | 구체화 필요 | 권한 판정 시 다음 우선순위로 평가합니다: 사용자 직접 거부 > 사용자 직접 허용 > 역할 거부 > 역할 허용. 동일 출처에서는 거부가 허용보다 우선합니다. | 4개 항목의 정확한 우선순위, 사용자 설정과 역할 설정 중 어느 쪽이 더 우선하는지 |
