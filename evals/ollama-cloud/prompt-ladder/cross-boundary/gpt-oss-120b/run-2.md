## 요약
- 구체화 필요 1건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 은유적 표현 “그릇”이 실제 동작(권한 저장·관리)을 가리키는지 불명확함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 구체적으로 어떤 데이터 구조·객체를 의미하는가 | 구체화 필요 | 권한을 저장하고 관리할 **데이터 구조(예: Permission 객체)**가 필요합니다. | 사용 중인 시스템에서 권한을 보관하는 구체적 구현(클래스·테이블·캐시 등) |

**문제 없는 문장**: 2, 3  

(2) 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. – 정보가 완전하고 은유·압축이 없음.  
(3) 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. – 적용 순서와 우선 규칙이 명시되어 있어 독해에 부담이 없음.
