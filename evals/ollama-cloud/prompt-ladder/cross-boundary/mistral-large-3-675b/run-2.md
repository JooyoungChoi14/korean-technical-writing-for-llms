## 요약
- 구체화 필요 1건 (`권한을 담아낼 그릇이 필요합니다.`), 나머지 2건은 통과

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 1) 어떤 구성 요소(클래스, 구조체, 테이블 등)가 권한을 저장하는가?<br>2) 권한을 '담아내는' 구체적인 동작(생성, 할당, 영속화 등)은 무엇인가? | 구체화 필요 | 권한을 저장할 데이터 구조(예: `Permission` 클래스 또는 `user_permissions` 테이블)가 필요합니다. | 해당 문서에서 이미 정의된 권한 모델이 있는지 확인 필요 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | - | - |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | - | 통과 | - | - |

### 통과 문장 설명
- **2번 문장**: "임시 권한"이라는 대상이 명확하고, "만료 시각 저장"과 "현재 시각 비교"라는 동작이 구체적으로 설명되어 있어 독자가 추가 추론 없이 이해할 수 있습니다.
- **3번 문장**: 권한 적용 순서와 우선 규칙("거부 우선")이 명확하게 기술되어 있으며, 독자가 추가 정보를 추론할 필요가 없습니다.
