## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 3번 문장의 우선순위 나열과 '거부 우선' 원칙이 서로 다른 결과를 만드는 조합

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 무엇인지 — 데이터 구조, 테이블, 필드, 클래스 중 어느 것인지 | 구체화 필요 | 권한 정보를 저장할 구조(예: 권한 테이블)가 필요합니다. | 도입하려는 저장 구조의 종류는 무엇입니까? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 나열 순서상 '사용자 직접 허용'이 '역할 거부'보다 앞서므로, 사용자 직접 허용 + 역할 거부 조합에서는 허용이 이깁니다. 그러나 '거부를 우선합니다'는 반대 결과를 지시합니다. | 의미 확인 필요 | (확인 후) 예: 사용자 직접 거부 > 역할 거부 > 사용자 직접 허용 > 역할 허용 순으로 적용합니다. | 사용자 직접 허용과 역할 거부가 동시에 성립할 때 최종 결과는 무엇입니까? |

## 통과
- 2: 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. — 대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청)이 모두 문장 안에서 확정됩니다.
