## 요약
- 구체화 필요 0건, 의미 확인 필요 2건(1번, 3번), 통과 1건(2번)
- 가장 큰 독해 부담: 3번 문장은 나열된 적용 순서와 "거부를 우선합니다"가 같은 조합에서 서로 다른 결과를 만들므로, 독자가 판정 규칙을 스스로 선택해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 가리키는 실제 대상(자료 구조·테이블·필드 등)과 "담아낼"에 해당하는 실제 동작(저장·보관) | 의미 확인 필요 | "권한 정보를 저장할 자료 구조가 필요합니다." — 비유를 제거한 최소안이며, "자료 구조" 자리는 확인 후 구체 대상으로 교체 | "그릇"의 구현 대상이 무엇인지(데이터베이스 테이블, 세션·토큰 필드, 메모리 구조 등) |
| 3번 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"의 의미(첫 번째 일치 규칙이 최종 결과가 되는지), "거부를 우선"의 적용 범위(전체 규칙 간인지 같은 출처 내인지), 사용자 직접 허용 + 역할 거부 조합의 최종 결과 | 의미 확인 필요 | 확인 결과에 따라 둘 중 하나. (a) 순서가 우선이면: "① 사용자 직접 거부 ② 사용자 직접 허용 ③ 역할 거부 ④ 역할 허용 순으로 첫 번째로 일치하는 규칙을 최종 결과로 적용합니다." (b) 거부 전체 우선이면: "거부 규칙(사용자 직접 거부 → 역할 거부)을 먼저 확인하고, 거부가 없을 때만 허용 규칙(사용자 직접 허용 → 역할 허용)을 적용합니다." | 사용자 직접 허용(나열 순서상 먼저 적용)과 역할 거부("거부 우선" 원칙상 우선)가 동시에 설정된 경우, 최종 결과는 허용인지 거부인지? "거부 우선"은 모든 규칙에 적용되는지, 같은 출처(사용자/역할) 안에서만 적용되는지? |

## 문제 없는 문장
- **2번 — 통과**: 대상(임시 권한), 동작(만료 시각 저장 → 현재 시각과 비교), 조건(각 요청), 결과(유효성 확인)가 문장 안에 모두 있어 독자가 추가로 복원할 정보가 없습니다.
