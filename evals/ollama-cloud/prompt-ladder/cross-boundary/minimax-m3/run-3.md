## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: "그릇" 비유가 도입하려는 타입과 그 연산(저장 외에 무엇을 할 수 있는지)을 한꺼번에 가리고, "거부 우선"이 평가 순서와 결합될 때 충돌 해결 범위와 평가 방식이 확정되지 않음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 타입/자료구조인지, 보관 외에 어떤 연산(조회·삭제·반복 등)을 제공하는지, 가시성 범위(공개/내부) | 구체화 필요 | 권한 항목 여러 개를 보관할 컬렉션 타입을 도입한다. | 구체적 타입(클래스·구조체·집합·사전 등), 보관 외에 노출할 연산, 가시성 범위 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"이 첫 일치 우선 채택인지 모든 규칙 누적 평가인지, "거부 우선"이 같은 적용 범위 내 충돌에만 한정되는지 모든 범위에서 우선인지, 어떤 규칙도 일치하지 않을 때의 기본값 | 의미 확인 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 적용하고, 거부 규칙이 허용 규칙보다 우선한다. | 평가 방식(첫 일치 우선 vs 누적), "우선"의 적용 범위(동일 범위 내 충돌 vs 전역), 규칙 미일치 시 기본 동작 |

## 통과한 문장
- 2번 "임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다."는 대상(임시 권한의 만료 시각), 동작(저장·현재 시각 비교), 조건(각 요청), 결과(유효성 판정)가 모두 드러나 있어 추가 구체화 없이 그대로 이해됩니다.
