## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 비유("그릇")가 실제 데이터 구조의 종류와 위치를 가리고, 명사 나열("거부/허용 네 개")이 평가 방식과 우선순위 규칙을 가림

## 통과 문장
- **2번** "임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다." — 주체(임시 권한), 동작(저장·비교·확인), 비교 대상(만료 시각 ↔ 현재 시각), 조건(각 요청)이 모두 드러나 문장 자체로 의미가 충분합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 종류의 구조(필드·토큰 클레임·객체·컬렉션 등)에 권한을 담는지, 그 구조가 어디에 위치하는지(요청 컨텍스트, 세션, DB 등) | 구체화 필요 | "권한을 보관할 구조가 필요합니다." (구체적 종류와 위치는 원문에서 확정 불가) | 권한을 실제로 보관할 데이터 구조의 종류와 위치 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"이 순차 평가인지 규칙 결합인지, "거부를 우선"이 목록 안의 순서만 가리키는 것인지, 아니면 어떤 거부가 모든 허용을 이기는 전역 규칙(deny-overrides)인지 | 의미 확인 필요 | 의미 확인 후 예시: "권한 판정은 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순서로 평가하며, 한 항목이라도 거부이면 최종 결과를 거부로 결정한다." | "거부를 우선"이 평가 순서만 의미하는지, 아니면 deny-overrides 같은 전역 규칙인지 |
