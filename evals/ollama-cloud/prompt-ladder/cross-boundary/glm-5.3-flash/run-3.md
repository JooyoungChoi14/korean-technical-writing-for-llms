## 요약
- 구체화 필요 1건(문장 1), 의미 확인 필요 1건(문장 3)
- 가장 큰 독해 부담: 문장 3 — 나열 순서와 '거부 우선' 원칙이 같은 조합에 대해 서로 다른 결과를 내므로, 독자가 어느 원칙이 이기는지 스스로 판단해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 지칭하는 실제 대상(변수·객체·저장소 등)과 '담아낸다'의 실제 동작(무엇을 어디에 저장하는지) | 구체화 필요 | 권한을 저장할 자료 구조가 필요합니다.(후보) | '그릇'에 해당하는 실제 대상은 무엇입니까? 원문만으로는 대상과 동작이 확정되지 않아 수정안을 후보로 두었습니다. |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 사용자 직접 허용과 역할 거부가 동시에 성립할 때의 최종 결과. 규칙을 적용하는 주체 | 의미 확인 필요 | 의도에 따라 선택: (a) 나열 순서 우선 — "…순서로 검사해 처음 일치하는 결과를 적용합니다" (b) 거부 전역 우선 — "역할 거부는 사용자 직접 허용보다 우선합니다" | 사용자 직접 허용과 역할 거부가 동시에 있을 때 의도된 최종 결과는 무엇입니까? 나열 순서를 그대로 적용하면 허용, '거부 우선'을 범주 무관 원칙
