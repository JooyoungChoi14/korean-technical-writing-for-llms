- 구체화 필요 0건, 의미 확인 필요 2건, 통과 1건
- 가장 큰 독해 부담: 3번. 한 문장 안에 나열 순서와 '거부 우선'이라는 두 규칙이 있고, 둘이 특정 조합에서 서로 다른 결과를 만듭니다.

|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 대상(권한 정의 스키마인지, 권한 부여 내역의 저장소인지), '담아낸다'의 실제 동작(정의인지 저장인지) | 의미 확인 필요 | 대상 확정 전까지 수정 불가. 확정 후 예: "권한을 저장할 저장소(또는 권한 모델)가 필요합니다." | 이 '그릇'은 권한의 종류를 정의하는 모델입니까, 사용자별 권한 부여 내역을 저장하는 대상입니까? |

## 통과
- **2번** — 대상(임시 권한), 동작(만료 시각 저장, 요청마다 현재 시각과 비교해 유효성 확인), 조건(각 요청)이 문장 안에 모두 표현되어 추론이 필요 없습니다.

## 의미 확인 필요

- **1번** — `[확인 필요]` '그릇'의 실제 대상을 원문만으로 확정할 수 없습니다.
  질문: 권한을 정의하는 모델(스키마)과 권한 부여 내역을 저장하는 저장소 중 어느 것을 말합니까?

- **3번** — `[확인 필요]` 나열 순서와 '거부를 우선합니다'가 모순되는 조합이 있습니다. **사용자 직접 허용 + 역할 거부**가 동시에 성립할 때, 나열 순서대로면 **허용**, '거부 우선' 원칙대로면 **거부**입니다. '거부 우선'이 사용자·역할 각 수준 *내부에서만* 거부를 먼저 검사한다는 뜻이라면 나열 순서와 일치하지만, 전역 원칙이라면 모순됩니다.
  질문: 이 조합에서 의도된 최종 결과는 허용입니까, 거부입니까?
