## 요약
- 구체화 필요 1건(3번), 의미 확인 필요 1건(1번), 통과 1건(2번)
- 가장 큰 독해 부담: 1번 — '그릇'이 가리키는 대상이 문장 어디에도 없어 독자가 전부 복원해야 합니다. 3번은 추측 부담과 별개로, 목록 순서와 뒤따르는 평가 문구가 같은 조합에 대해 서로 다른 결과를 주는 상충이 있습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'의 실체(자료 구조·저장소·UI 영역·모듈 중 무엇), '담아낸다'의 실제 동작(저장·표시·등록 중 무엇), 그릇이 필요한 주체 | 의미 확인 필요 | 원문만으로는 대상을 확정할 수 없습니다. 저장이 의도라면: "권한을 저장할 자료 구조가 필요합니다." `[확인 필요]` | '그릇'이 가리키는 실제 대상은 무엇입니까? '담아낸다'는 저장·표시·등록 중 어느 동작입니까? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '거부 우선'의 적용 범위 — 같은 수준(사용자/역할) 안에서만인지 전체 규칙을 통틀어인지. 목록 순서대로면 '사용자 직접 허용 + 역할 거부' 조합의 결과는 허용이지만, '거부 우선' 문구대로면 거부. 또한 처음 일치하는 규칙이 최종 결정인지, 규칙이 없을 때 기본값 | 구체화 필요 | 권한 규칙은 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 적용합니다. 이 순서에서 거부가 허용보다 우선하는 것은 같은 수준(사용자 직접 지정 또는 역할) 안에서이며, 사용자 직접 허용은 역할 거부보다 앞서 적용됩니다. | (a) '사용자 직접 허용'과 '역할 거부'가 동시에 성립할 때 의도된 최종 결과는 허용입니까, 거부입니까? 목록 순서(허용)와 '거부 우선' 문구(거부)가 이 조합에서 상충합니다. (b) '적용'이 처음 일치하는 규칙으로 최종을 결정하는 방식입니까? (c) 어떤 규칙도 일치하지 않을 때 기본 결과는 무엇입니까? |
