## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 권한을 담는 '그릇'이 어떤 데이터 구조인지, '거부 우선'이 어떤 평가 로직인지 독자가 추측해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 어떤 프로그래밍 요소(객체, 변수 등)인지, '담아낸다'가 어떤 동작(저장, 보유 등)인지 | 구체화 필요 | 권한을 저장할 데이터 구조가 필요합니다. | '그릇'이 구체적으로 어떤 요소(객체, 데이터베이스 테이블 등)를 의미하는가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 무엇을(규칙을) 적용하는지, '거부를 우선한다'는 구체적인 평가 로직이 무엇인지 | 구체화 필요 | 권한을 검사할 때 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 평가하며, 거부 규칙이 일치하면 허용 규칙보다 우선하여 접근을 거부합니다. | '거부를 우선한다'는 것이 첫 번째로 일치하는 규칙을 따르는 것인지, 거부 규칙이 하나라도 존재하면 무조건 거부하는 것인지? |

**문제가 없는 문장**
- 2번 문장: 대상(임시 권한), 동작(만료 시각 저장, 시각 비교, 유효성 확인)이 명확하므로 통과입니다.
