## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 권한을 저장할 실제 구조를 '그릇'이라는 비유로 가렸고, '우선한다'는 표현이 평가 순서인지 충돌 시 적용 규칙인지 불분명합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장하거나 할당하는 실제 데이터 구조나 속성 | 구체화 필요 | 권한을 저장할 데이터 구조(또는 속성)가 필요합니다. | '그릇'이 가리키는 실제 구현체(예: 데이터베이스 필드, 객체 속성, 클레임)는 무엇입니까? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '우선한다'는 것이 평가 순서상 먼저라는 뜻인지, 아니면 충돌 시 거부 규칙이 허용 규칙을 무효화한다는 뜻인지 | 의미 확인 필요 | 권한 판정 시 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 평가하며, 거부 규칙이 있으면 허용 규칙보다 우선하여 접근을 차단합니다. | '거부를 우선한다'는 것이 단순히 평가 순서가 빠르다는 뜻인지, 아니면 충돌 시 거부가 허용을 덮어쓴다는 우선순위 규칙인지 확인이 필요합니다. |

- **통과**: 문장 2 (임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.) — 대상, 동작, 조건이 문장 안에서 명확하게 드러납니다.
