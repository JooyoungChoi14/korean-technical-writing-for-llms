## 요약
- **구체화 필요 2 건**, **통과 1 건**
- 가장 큰 독해 부담: 1 번 문장의 비유적 표현 (`그릇`) 이 실제 기술 개체를 특정하기 어렵게 합니다. 2 번 문장은 데이터 개체가 로직을 수행하는 것으로 서술되어 주체가 모호합니다.

| 위치 | source | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | `그릇` 이指하는 실제 기술 개체 (객체, DB 테이블, 토큰 클레임 등) | 구체화 필요 | 권한 정보를 저장할 **[객체/테이블/클레임]** 가 필요합니다. | 권한 데이터를 담는 실제 구현체 종류 |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 권한 데이터 자체가 검증 로직을 수행하는지, 시스템 모듈이 수행하는지 | 구체화 필요 | **시스템은** 임시 권한의 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 검증 로직의 실제 주체 (모듈/미들웨어 등) |

## 통과한 문장
- **문장 3:** `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
  - **이유:** 권한 평가 순서와 우선순위 규칙 (Deny Overrides) 이 명확하게 서술되어 있으며, 기술적 모호성이 없습니다.
