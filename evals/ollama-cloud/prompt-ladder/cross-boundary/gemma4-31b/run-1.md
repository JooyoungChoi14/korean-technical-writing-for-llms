## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`적용해 거부를 우선`)로 인해 실제 구현 대상과 로직의 방향을 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 실제 구현체(클래스, DB 테이블, 객체 등)와 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [객체/테이블/데이터 구조]가 필요합니다. | '그릇'이 구체적으로 어떤 기술적 요소(예: PermissionContainer 클래스 등)를 지칭하는가? |
| 2번 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | (유지) | - |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 무엇이 이 순서대로 검사하는지(주체), '거부를 우선한다'는 것이 전체 순서 중 어느 단계의 거부를 의미하는지(범위) | 구체화 필요 | [권한 검사 모듈]은 '사용자 직접 거부 $\rightarrow$ 사용자 직접 허용 $\rightarrow$ 역할 거부 $\rightarrow$ 역할 허용' 순으로 확인하며, 상위 단계에서 거부 설정이 있으면 즉시 거부로 판정합니다. | 1. 검사를 수행하는 주체는 무엇인가? <br> 2. '거부 우선'이 모든 단계의 거부를 의미하는지, 혹은 특정 우선순위 내에서의 충돌 해결 원칙인지 확인 필요. |
