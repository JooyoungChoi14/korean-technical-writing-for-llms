## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`적용해 거부를 우선`)로 인해 실제 구현 대상과 동작을 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 실제 구현체(클래스, 테이블, 객체 등)와 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [데이터 구조/객체]가 필요합니다. | '그릇'이 구체적으로 무엇을 의미하는가? (예: 권한 관리 클래스, DB 테이블 등) |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | (유지) | - |
