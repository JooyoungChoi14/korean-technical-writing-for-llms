## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 1번 문장의 비유(‘그릇’)가 실제 구현 대상을 전혀 드러내지 않음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | ‘그릇’이 가리키는 구현체(필드, 컬럼, 테이블, 객체, 변수, 캐시 키 등)와 그릇에 담기는 권한의 구체적 형태(문자열, 비트마스크, JSON, 레퍼런스 등) | 구체화 필요 | 권한을 저장할 **필드/컬럼/속성**을 추가합니다. | 권한이 어떤 자료형으로, 어느 테이블 또는 객체에 저장되는지 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | — | 통과 | (변경 불필요) | — |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | ‘적용해’가 의미하는 평가 알고리즘(순차 평가 후 최초 매칭? 전체 수집 후 거부 우선 병합?)과 ‘사용자 직접/역할’ 권한이 어디서 오는 데이터인지 | 의미 확인 필요 | 권한 평가 순서를 **사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용**으로 정의하고, **거부 항목이 하나라도 있으면 즉시 거부**합니다. | 평가 알고리즘(쇼트서킷 vs 전체 병합)과 각 권한 소스의 조회 경로 |

### 통과 문장 (별도 표시)
- **2번**: 주체(임시 권한)·동작(저장·비교·확인)·조건(각 요청)·결과(유효성 판단)가 문장 안에서 완결됨.
