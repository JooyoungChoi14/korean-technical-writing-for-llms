## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 1번 문장의 '그릇'이 가리키는 기술적 구현체(자료구조·객체·스토리지 등)가 전혀 드러나지 않음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 무엇인가? (객체, 테이블, 토큰 필드, 컨텍스트 변수, 스토리지 등) | 구체화 필요 | 권한을 저장할 **자료구조/객체/필드**가 필요합니다. | 어떤 구현체(클래스, DB 컬럼, JWT 클레임, 세션 저장소 등)를 '그릇'으로 삼는지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 구체적 동작(평가·병합·우선순위 판정), '거부를 우선한다'의 정확한 의미(첫 번째 거부에서 즉시 차단 vs 전체 평가 후 거부 우세) | 의미 확인 필요 | 평가 순서: ① 사용자 직접 거부 ② 사용자 직접 허용 ③ 역할 거부 ④ 역할 허용. **어느 단계에서 거부 판정이 나면 즉시 차단하는지, 아니면 모두 평가 후 거부 우세로 합산하는지** 명시 | 평가 알고리즘이 '첫 거부 즉시 차단(short-circuit)'인지 '전체 평가 후 거부 우선 합산'인지 |

### 통과 (문제 없음)
**2. 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.**  
대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청 시), 결과(유효성 판정)가 문장 안에서 모두 명시되어 있어 독자가 추가 추론 없이 이해할 수 있습니다.
