- 가장 큰 독해 부담: metaphor (그릇)와 생략된 주체·대상으로 인해 독자가 구체적인 동작이나 구조를 추측해야 함

| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 구체적으로 무엇을 가리키는가? (토큰, credential 객체, 서버측 저장소 등) | 구체화 필요 | 권한을 저장할 토큰 또는 credential 객체가 필요합니다. | 권한을 보관하는 구체적인 메커니즘은 무엇인가? (예: JWT, 세션 ID, 서버측 토큰) |
