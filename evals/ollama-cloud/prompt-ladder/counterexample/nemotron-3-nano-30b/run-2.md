| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 실제 어떤 구조·객체·데이터형을 가리키는지 | 의미 확인 필요 | 권한을 저장하거나 관리할 객체가 필요합니다. | 해당 구조가 권한을 담을 수 있는 구체적인 형태(예: API, DB 테이블, 설정 파일) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | “거부를 우선합니다”가 거부와 허용 중 어느 것을 우선시하는지, 역할 거부·허용의 적용 순서 | 의미 확인 필요 | 사용자 직접 거부 > 사용자 직접 허용 > 역할 거부 > 역할 허용 순으로 적용하며, 거부 동작이 허용보다 우선합니다. | 거부 우선 규칙이 시스템 전체에서 일관되게 적용되는지, 역할 기반 결정 로직의 정의 |
