- 가장 큰 독해 부담: 3번의 적용 순서와 ‘거부 우선’ 원칙이 서로 어떻게 결합되는지가 모호합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 보관할 실제 자료 구조나 저장 방식 | 구체화 필요 | 권한을 저장할 자료 구조가 필요합니다. | 어떤 자료 구조(목록, 집합, 맵 등)를 사용하는지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 적용 순서와 ‘거부 우선’ 규칙의 정확한 관계. 사용자 직접 허용이 역할 거부보다 앞서면 역할 거부가 무시되는지 여부 | 의미 확인 필요 | 같은 범위에서는 거부를 허용보다 먼저 적용하고, 범위가 다르면 사용자 직접 설정을 역할 설정보다 먼저 적용한다고 명시하세요. 예: 사용자 직접 거부 > 역할 거부 > 사용자 직접 허용 > 역할 허용. | 사용자 직접 허용과 역할 거부가 동시에 있을 때 어느 쪽이 우선하는지 |
