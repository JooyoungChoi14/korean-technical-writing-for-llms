## 요약
- **구체화 필요 2 건**, 통과 1 건
- **가장 큰 독해 부담:** 1 번 문장의 비유적 표현 (`그릇`) 과 2 번 문장의 주체 오류 (`권한` 이 확인한다) 가 기술적 구현을 추측하게 만듭니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 문장 | 권한을 담아낼 그릇이 필요합니다. | `그릇` 이 지칭하는 실제 기술 구조 (토큰, 세션, 클레임 집합 등) | 구체화 필요 | 권한 정보를 저장할 **구조체 (또는 토큰/세션)** 가 필요합니다. | 권한을 저장하는 실제 단위是什么인가? |
| 2 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 유효성을 실제로 확인하는 주체 (시스템, 미들웨어, 인증 모듈) | 구체화 필요 | 시스템은 임시 권한의 만료 시각을 저장하고, 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 권한 데이터 자체가 로직을 수행하는가, 아니면 시스템이 권한 데이터를 검증하는가? |

## 통과한 문장
- **3 문장:** `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
  - **이유:** 권한 우선순위 정책을 설명하는 문장으로, 명사 나열이 있으나 정책 평가 순서와 결과 (`거부 우선`) 가 명확하여 추가 수정 없이 의도 전달이 가능합니다.
