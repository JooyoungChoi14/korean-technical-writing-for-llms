## 요약
- 구체화 필요 3건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 ‘그릇’이라는 비유로 인해 실제로 어떤 프로그래밍 요소가 필요한지 알 수 없음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | ‘그릇’이 실제로 어떤 자료구조·객체·필드인지, 권한을 어떻게 담는지(저장? 포함? 관리?) | 구체화 필요 | 권한을 저장할 필드(또는 객체/자료구조)가 필요합니다. | ‘그릇’이 구체적으로 어떤 프로그래밍 요소(클래스, 필드, 변수, 테이블 등)를 가리키는가? |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 누가(어느 모듈/컴포넌트가) 저장하고 비교하는지, 유효성 확인 후 어떤 결과(승인/거부/예외)가 발생하는지 | 구체화 필요 | 임시 권한 객체는 만료 시각을 저장하며, 서버는 각 요청마다 현재 시각과 비교해 만료되었으면 요청을 거부합니다. | 저장과 비교의 주체는 임시 권한 객체 자신인가, 외부 모듈인가? 유효성 확인 결과로 취하는 조치는 무엇인가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | ‘적용’의 주체(정책 엔진 등), ‘거부를 우선’의 구체적 의미(평가 순서인가 우선순위 가중치인가) | 구체화 필요 | 정책 엔진은 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 규칙을 평가하여, 거부 규칙을 먼저 적용합니다. | ‘적용’이 평가 순서를 의미하는가, 아니면 우선순위 점수를 의미하는가? 주체는 무엇인가? |
