## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 1은 "그릇"이라는 비유가 실제 자료구조·API 형태를 가리고, 문장 3은 "거부를 우선"이 순차 우선인지 절대 우선인지 확정되지 않음

## 통과한 문장
- **문장 2** `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.`
  - 주체(임시 권한), 동작(저장·비교), 시점(각 요청에서), 결과(유효성 확인)가 모두 드러나 있어 문장 자체로 이해 가능. 통과.

## 문제 발견

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | `권한을 담아낼 그릇이 필요합니다.` | "그릇"이 클래스인지 인터페이스인지 단순 속성 묶음인지, 어떤 연산(추가/검사/회수/만료)을 제공할지 | 구체화 필요 | `권한 항목을 보관할 [자료구조/타입]가 필요합니다.` (예: `Set<Permission>`, 권한 인터페이스 등) | 도입하려는 실제 타입 또는 클래스명 |
| 3 | `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.` | (a) 순차 평가 후 첫 매치 채택인지, (b) 모든 규칙을 평가한 뒤 거부가 허용을 항상 무효화하는지. 또한 "적용"이 덮어쓰기인지 누적인지 | 의미 확인 필요 | 해석 (a) 기준: `사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 첫 매치를 채택합니다.`<br>해석 (b) 기준: `네 규칙을 모두 평가하고, 거부 결정이 하나라도 있으면 허용을 무효화합니다.` | 권한 해석 알고리즘이 "first-match" 방식인지 "deny-overrides" 방식인지 |

## 의미 확인 필요
- **문장 3** 권한 해석의 실제 우선 규칙(first-match vs deny-overrides)이 원문에서 확정되지 않음. 다음 질문이 필요함: "거부 결정이 다른 출처의 허용 결정을 항상 무효화합니까, 아니면 순서상 먼저 나오는 결정만 채택합니까?"
