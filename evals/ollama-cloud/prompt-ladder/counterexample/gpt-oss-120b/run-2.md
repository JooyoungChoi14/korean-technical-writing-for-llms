## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 1번 문장의 은유적 표현, 3번 문장의 적용 대상·조건 불명확  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 실제 어떤 저장소·구조를 의미하는가? (예: DB 테이블, 메모리 캐시 등) | 구체화 필요 | 권한을 저장할 저장소가 필요합니다. | 권한을 보관할 구체적인 구현(예: 테이블, 캐시) 여부 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 이 순서가 적용되는 **대상**(예: 권한 평가, 접근 제어)와 **조건**(예: 동일 권한 충돌 시) | 구체화 필요 | 권한 평가 시, “사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용” 순으로 적용하며, 거부가 허용보다 우선합니다. | 적용 범위(전체 시스템·특정 모듈)와 충돌 상황 정의 |
