## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`적용해 거부를 우선`)로 인해 실제 구현 방식과 우선순위 결정 로직을 독자가 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 실제 기술적 대상(클래스, DB 테이블, 객체, 변수 등)과 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [데이터 구조/객체/테이블]이 필요합니다. | '그릇'이 구체적으로 어떤 구현체(예: PermissionContainer 클래스 등)를 의미하는가? |
| 2번 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | (유지) | - |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 어떤 주체가 이 순서로 검사하는지, '거부를 우선한다'는 것이 전체 순서보다 우선한다는 것인지 혹은 동일 레벨 내에서의 우선순위인지 | 구체화 필요 | [권한 검증 모듈]은 '사용자 직접 거부 $\rightarrow$ 사용자 직접 허용 $\rightarrow$ 역할 거부 $\rightarrow$ 역할 허용' 순으로 권한을 확인하며, 동일 조건 내에서는 거부 설정을 우선하여 적용합니다. | 1. 검증을 수행하는 주체는 무엇인가? <br> 2. '거부 우선'이 전체 리스트의 순서(사용자 거부가 가장 먼저)를 의미하는 것인가, 아니면 특정 조건 내에서의 우선순위인가? |
