## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`적용해 거부를 우선`)로 인해 실제 구현 방식과 우선순위 결정 로직을 독자가 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 구체적인 기술적 대상(DB 테이블, 클래스, 객체, 설정 파일 등)과 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [데이터 구조/객체/테이블]이 필요합니다. | '그릇'이 구체적으로 무엇을 구현해야 함을 의미하는가? |
| 2번 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | - | - |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 권한을 판정하는 주체(시스템/모듈)와 '거부를 우선한다'는 규칙이 전체 순서 중 어디에 적용되는지(전체 최우선인지, 동일 레벨 내 우선인지) | 구체화 필요 | [권한 판정 모듈]은 '사용자 직접 거부 $\rightarrow$ 사용자 직접 허용 $\rightarrow$ 역할 거부 $\rightarrow$ 역할 허용' 순으로 검토하며, 상위 단계에서 거부 설정이 발견되면 즉시 거부로 판정합니다. | 1. 판정을 수행하는 주체는 무엇인가? <br> 2. '거부 우선'이 전체 순서의 우선순위를 의미하는가, 아니면 특정 조건에서의 우선순위인가? |
