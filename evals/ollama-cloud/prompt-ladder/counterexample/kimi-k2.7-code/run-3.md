- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 "그릇" 비유로 인해 실제 구현 대상과 동작을 추측해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 클래스, 테이블, 필드, 모델 등 어떤 구현체를 가리키는지; "담아낸다"가 저장, 표현, 전달 중 어떤 동작인지 | 구체화 필요 | 권한을 저장할 데이터 구조가 필요합니다. [구체적 구현체는 원문 미확정] | "그릇"이 가리키는 구현체의 종류와 "담아낸다"의 동작 범위 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "순으로 적용"이 권한 평가 우선순위인지, 규칙 적용 순서인지; "거부를 우선"이 동일 리소스 충돌 시에만 성립하는지 | 구체화 필요 | 권한을 평가할 때 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 규칙을 적용하며, 충돌할 경우 거부 규칙을 허용 규칙보다 우선합니다. [충돌 조건 원문 미확정] | "적용"의 대상(권한 평가 절차)과 "거부 우선"이 성립하는 조건 |
