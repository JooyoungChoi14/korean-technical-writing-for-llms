- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 "그릇"이 가리키는 구현체를 알 수 없어 독자가 비유에서 실제 개념을 복원해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 클래스, 데이터 모델, 테이블, 필드 중 무엇인지; "담아낸다"는 저장, 표현, 전달 중 무엇인지 | 구체화 필요 | 권한을 [저장/표현]할 [데이터 구조/클래스/모델]이 필요합니다. | "그릇"이 가리키는 구현체의 종류와 "담아낸다"의 구체적 동작 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "순으로 적용"이 평가 우선순위인지, "거부를 우선"이 모든 거부가 모든 허용보다 우선한다는 의미인지, 아니면 특정 범위 내에서만 우선인지 | 구체화 필요 | 규칙을 다음 우선순위로 평가합니다: 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용. | "순으로 적용"의 정확한 의미(앞선 규칙이 뒤를 덮어쓰는지, 먼저 평가하는지)와 "거부를 우선"의 적용 범위 |
