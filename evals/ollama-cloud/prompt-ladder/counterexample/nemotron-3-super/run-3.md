## 요약
- 구체화 필요 2건, 의미 확인 필요 0건  
- 가장 큰 독해 부담: metaphorical expression (“그릇”)과 누락된 동사 (“적용”)으로 인해 대상·동작을 추측해야 함  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|------------------------|------|--------|--------------|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 저장소(변수·필드·토큰 등)가 권한을 보관하는가? | 구체화 필요 | 권한을 저장할 변수(또는 필드)가 필요합니다. | 권한을 실제로 보관하는 데이터 구조(예: user.permission 필드, 액세스 토큰)는 무엇인가? |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 무엇이 “적용”되는가? (규칙·정책·플래그 등) | 구체화 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 적용하여 거부를 우선시합니다. | 네 가지 항목이 구체적으로 어떤 접근 제어 규칙(또는 정책)인지, 그리고 해당 순서가 실제로 어떻게 구현되는지 |

**문장 2**: 문제 없음 (통과)  
> 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.
