## 요약
- 구체화 필요 2건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 1번 문장은 핵심 대상을 비유로만 표현해 구현 대상(필드/객체/테이블/스코프 등)을 특정할 수 없음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 무엇이 '그릇'인가(필드·객체·테이블·스코프·컨텍스트 등), 누가 생성·관리하는가, 어떤 동작(할당·조회·검사)을 지원해야 하는가 | 구체화 필요 | 권한을 저장할 **필드/객체/자료구조**가 필요합니다. | '그릇'이 가리키는 구체적인 구현체(데이터베이스 컬럼, 인메모리 객체, 토큰 클레임 등)는 무엇입니까? |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 주체 '임시 권한'이 스스로 저장·비교하는가, 실제로는 시스템/미들웨어가 수행하는가 | 의미 확인 필요 | 시스템은 임시 권한의 **만료 시각을 기록**하고, **각 요청 시 현재 시각과 비교해 유효 여부를 판정**합니다. | 만료 시각을 기록·비교하는 주체(미들웨어, 인증 서비스, 게이트웨이 등)는 무엇입니까? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용하다'의 구체적 동작(평가·검사·병합·차단), '거부를 우선한다'의 정확한 의미(첫 거부에서 즉시 차단 vs 전체 평가 후 거부 우세) | 구체화 필요 | 평가 순서는 **사용자 명시 거부 → 사용자 명시 허용 → 역할 거부 → 역할 허용**이며, **어느 단계에서든 거부 판정이 나오면 즉시 접근을 차단**합니다. | '거부 우선'이 '첫 거부 즉시 차단(short-circuit)'인지, '전체 평가 후 거부 우세'인지 어느 쪽입니까? |
