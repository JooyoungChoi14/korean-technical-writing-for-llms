## 요약
- 구체화 필요 1건(3번), 의미 확인 필요 1건(1번), 통과 1건(2번)
- 가장 큰 독해 부담: 1번 — "그릇" 비유가 대상과 동작을 모두 대체해, 문장만으로는 무엇을 확보하라는 것인지 특정할 수 없습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"의 실제 대상(권한을 보관하는 자료 구조, 권한의 묶음 단위, 별도 저장소 등), "담아낸다"에 해당하는 실제 동작, 이것이 요구사항인지 구현 항목인지 | 의미 확인 필요 | 권한을 저장할 [대상]이 필요합니다 — 대상 확정 후 채움 | 이 "그릇"에 해당하는 실제 구성 요소는 무엇인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "직접"의 뜻(역할을 통하지 않고 사용자에게 바로 설정된 것), "거부를 우선한다"의 범위 — 같은 수준 안에서인지, 역할 거부가 사용자 허용보다도 우선인지, 나열 순서대로 처음 해당하는 규칙이 결과를 정하는지 | 구체화 필요 | 권한 규칙은 사용자에게 직접 설정한 거부, 사용자에게 직접 설정한 허용, 역할에 설정된 거부, 역할에 설정된 허용 순으로 적용합니다. 이 순서에서는 사용자 설정이 역할 설정보다 먼저 적용되고, 같은 수준 안에서는 거부가 허용보다 먼저 적용됩니다. | 사용자 직접 허용과 역할 거부가 동시에 있을 때의 결과 — 나열 순서대로면 허용이 먼저 적용되어 "거부 우선" 요약과 어긋납니다. 모든 거부가 모든 허용보다 우선하는 것이 의도라면 순서 자체가 다른지 확인 |

**통과(별도 표시)**: 2번 — 대상(임시 권한), 동작(만료 시각 저장, 현재 시각과 비교), 조건(각 요청)이 문장 안에 모두 들어 있어 추가 추론이 필요 없습니다.
