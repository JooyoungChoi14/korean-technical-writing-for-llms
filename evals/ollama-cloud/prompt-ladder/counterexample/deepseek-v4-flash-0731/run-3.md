## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 3번 문장에서 나열된 적용 순서와 '거부를 우선'이라는 정책이 서로 충돌하여, 실제 판정 규칙을 독자가 재구성해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 무엇인지(변수, 필드, 테이블, 자료 구조) | 구체화 필요 | 권한을 저장할 필드(또는 자료 구조)가 필요합니다. | 권한을 실제로 보관하는 대상이 데이터베이스 필드인지, 메모리 객체인지, 토큰 클레임인지 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '거부를 우선'이 나열 순서와 충돌합니다. 사용자 직접 허용이 역할 거부보다 먼저 나오는데, 거부가 우선이라면 역할 거부가 이겨야 하는지, 아니면 순서대로 첫 번째 일치가 적용되는지 | 의미 확인 필요 | (거부가 절대 우선이라면) 사용자 직접 거부, 역할 거부, 사용자 직접 허용, 역할 허용 순으로 적용합니다. <br> (순서대로 첫 번째 일치를 적용한다면) 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용합니다. | 거부가 허용보다 항상 우선하는 정책인지, 아니면 나열된 순서대로 첫 번째 일치 규칙을 적용하는지 |

## 통과
- 문장 2: 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. (대상, 동작, 조건이 모두 명확하며 수정이 필요 없습니다.)
