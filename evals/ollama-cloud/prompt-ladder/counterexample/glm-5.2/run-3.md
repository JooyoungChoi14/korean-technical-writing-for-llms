## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 '그릇'이 실제 기술 대상을 가려 독자가 구현체를 추측해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장하거나 표현할 실제 기술 대상(자료 구조, 객체, 필드 등) | 구체화 필요 | 권한 정보를 저장할 자료 구조(또는 객체)가 필요합니다. | '그릇'이 가리키는 실제 구현체(클래스, 구조체, 토큰 등) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 규칙을 평가하는 실제 동작(일치하는 첫 규칙을 찾을 때까지 순서대로 확인하는지)과 '거부를 우선한다'의 정확한 의미 | 구체화 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 평가하여 일치하는 첫 번째 결과를 적용합니다. | 규칙 평가 중 일치 항목을 만나면 즉시 평가를 중단하는지, 아니면 모두 평가 후 거부가 있으면 거부를 선택하는지 |

## 통과
- **2번 문장:** `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.` (대상, 동작, 조건, 결과가 문장 안에서 명확하게 제공됩니다.)
