## 요약

- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 "그릇"이 어떤 구현체인지 문장만으로 확정할 수 없고, 문장 3의 "적용"이 어떤 평가 방식인지 추측해야 합니다.
- 문장 2는 통과입니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 지칭하는 구현체—클래스, 필드, 토큰, 자료 구조 중 어느 것인지 | 구체화 필요 | 권한 정보를 저장할 `[확인 필요]`가 필요합니다. | "그릇"이 가리키는 구체적인 구현체는 무엇입니까? (예: 데이터 클래스, 데이터베이스 필드, JWT 클레임 등) |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"의 평가 방식(최초 일치 우선? 전체 평가 후 거부 우선?), 이 규칙을 평가하는 주체 | 구체화 필요 | 권한 판정 시 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 평가하여 거부를 우선합니다. | "순으로 적용"이 나열된 순서대로 평가해 첫 번째로 일치하는 규칙을 적용한다는 뜻입니까, 아니면 네 규칙을 모두 확인한 뒤 거부가 하나라도 있으면 거부한다는 뜻입니까? |

**문장 2 — 통과:** 대상(임시 권한), 동작(만료 시각 저장·현재 시각 비교), 조건(각 요청), 결과(유효성 확인)가 문장 안에서 충분히 드러납니다.
