## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장에서 "그릇"이라는 비유가 실제 데이터 구조나 객체를 가려, 독자가 구현 대상을 추측해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 보관하는 구체적 대상(데이터 구조, 객체, 컨텍스트 등)이 무엇인지 | 구체화 필요 | 권한 정보를 보관할 데이터 구조(또는 객체)가 필요합니다. | "그릇"이 가리키는 실제 구현체가 무엇인가? (예: 컨텍스트 객체, 권한 컨테이너, 세션 저장소 등) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 누가 규칙을 적용하는지, "거부를 우선"이 실제로 어떤 해결 방식(최초 일치 규칙 적용, 충돌 시 거부 우선 등)으로 구현되는지 | 구체화 필요 | 권한 평가 시 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 확인하여 가장 먼저 일치하는 규칙을 적용합니다. | 해결 방식이 "최초 일치 규칙 적용"인가, 아니면 "모든 규칙을 평가 후 거부 우선"인가? |

**문제 없는 문장:**
- 2번: 만료 시각 저장, 요청 시 현재 시각 비교, 유효성 확인까지 대상·동작·조건·결과가 문장 안에서 모두 드러납니다.
