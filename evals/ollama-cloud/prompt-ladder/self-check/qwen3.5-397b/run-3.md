## 판정 근거

**문장 1 (구체화 필요)**
- rubric.ko.md 의「동작을 대신하는 비유」항목에 해당
- '그릇'이라는 비유가 실제 기술 구성 요소 (DB 테이블, 클래스, 토큰 필드 등) 를 가려 독자가 복원 작업 필요
- 수정 시 실제 저장 매체 또는 구조를 명시해야 함

**문장 2 (통과)**
- 주체 (임시 권한), 동작 (저장·비교·확인), 조건 (각 요청에서), 결과 (유효성 확인) 가 모두 명시됨
- '임시 권한'이 주체인 것은 약간의 의인화이나 기술 문서에서 관용적으로 허용되는 수준
- semantic-fidelity.ko.md 기준에서 주체·방향·조건·결과 모두 보존됨

**문장 3 (구체화 필요)**

- 예: 사용자 허용 + 역할 거부 충돌 시 최종 결과가 무엇인지 독자가 추측해야 함
