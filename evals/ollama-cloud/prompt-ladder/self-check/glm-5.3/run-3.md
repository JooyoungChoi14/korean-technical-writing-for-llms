## 요약
- 구체화 필요 2건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 3의 "거부를 우선합니다" — 나열 순서상 사용자 직접 허용이 역할 거부보다 앞서지만, "거부를 우선"을 모든 출처에 적용되는 규칙으로 읽으면 이 순서와 충돌합니다. 독자는 "사용자 직접 허용과 역할 거부가 동시에 있을 때 어느 쪽이 이기는지"를 스스로 추측해야 합니다.
