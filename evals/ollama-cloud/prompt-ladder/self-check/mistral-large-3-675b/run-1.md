## 요약
- 구체화 필요 1건 (`권한을 담아낼 그릇이 필요합니다.`), 나머지 2건은 통과

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | (1) 어떤 종류의 권한을 저장하는가? (2) 그릇이란 구체적으로 데이터 구조, 클래스, 변수 중 무엇인가? (3) 권한을 담는 목적(저장, 전달, 검증 등)은 무엇인가? | 구체화 필요 | 권한을 저장하고 관리할 데이터 구조(예: `Permission` 클래스 또는 `Map<권한 유형, 만료 시각>`)가 필요합니다. | (1) 저장하는 권한의 종류(임시 권한, 역할 기반 권한 등) (2) 그릇의 구현 방식(클래스, 맵, DB 테이블 등) |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | - | - |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | - | 통과 | - | - |

---
### 통과 문장 설명
- **문장 2**: "임시 권한"이라는 대상과 "저장", "비교", "유효성 확인"이라는 동작이 명확히 드러나며, 조건(요청 시점)과 결과(유효성 판단)도 포함되어 있어 독자가 추가 추론 없이 이해할 수 있습니다.
- **문장 3**: 권한 적용 우선순위가 구체적으로 나열되어 있고, "거부를 우선한다"는 규칙이 명확히 서술되어 있어 정보가 충분합니다. "사용자 직접"과 "역할"이라는 용어도 기술 문서에서 흔히 사용되는 용어로, 별도 설명 없이도 이해 가능합니다.
