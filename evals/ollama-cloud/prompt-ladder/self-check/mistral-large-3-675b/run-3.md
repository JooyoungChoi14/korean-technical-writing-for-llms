## 요약
- **구체화 필요 1건** (문장 1): 동작을 비유로만 설명해 실제 구현 방식(데이터 구조, 저장 위치, 접근 방식)을 독자가 추론해야 함.
- **통과 2건** (문장 2, 3): 대상, 동작, 조건, 결과가 명확하게 기술됨.

---

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | `권한을 담아낼 그릇이 필요합니다.` | 1. "그릇"이 구체적으로 어떤 데이터 구조(예: 객체, 배열, DB 테이블)를 가리키는가?<br>2. 권한을 어디에 저장하고 어떻게 접근하는가?<br>3. "담아내다"의 동작이 저장, 전달, 검증 중 무엇인지? | 구체화 필요 | `권한을 저장할 데이터 구조(예: 사용자별 권한 객체 또는 DB 테이블)가 필요합니다.` | "그릇"이 프로젝트에서 이미 정의된 용어인지? 정의되지 않았다면 어떤 구현 방식을 의도하는지? |

---

### 통과한 문장
- **문장 2**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.`
  → 저장 대상(만료 시각), 동작(비교), 조건(요청 시점), 결과(유효성 확인)가 명확함.
- **문장 3**: `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
  → 적용 순서와 우선 규칙(거부 우선)이 구체적으로 기술됨.
