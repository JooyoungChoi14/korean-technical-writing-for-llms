## 요약
- **구체화 필요 1건** (문장 1): 동작을 비유로 대체하여 대상과 실제 동작이 모호함
- **통과 2건** (문장 2, 3): 동작과 조건이 명확하게 기술됨

---

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | `권한을 담아낼 그릇이 필요합니다.` | 1. "그릇"이 구체적으로 어떤 데이터 구조(예: 변수, 객체, DB 테이블)를 가리키는가?<br>2. "담아내다"의 실제 동작(예: 저장, 전달, 캐싱)은 무엇인가?<br>3. 권한의 범위(예: 사용자별, 세션별, API별)는 무엇인가? | 구체화 필요 | `권한 정보를 저장할 데이터 구조(예: 세션 객체 또는 DB 테이블)가 필요합니다.` | "그릇"이 가리키는 구체적인 구현체는 무엇입니까? |

---

### 통과한 문장
- **문장 2**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.`
  → 저장 대상(만료 시각), 동작(비교), 조건(요청 시점)이 명확함.
- **문장 3**: `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
  → 우선순위 규칙과 적용 대상이 명확하게 기술됨.
