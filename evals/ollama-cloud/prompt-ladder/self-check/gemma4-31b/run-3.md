## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`~순으로 적용`)로 인해 실제 구현 방식(데이터 구조 및 처리 로직)을 독자가 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 실제 기술적 대상(클래스, DB 테이블, 객체, 변수 등)과 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [데이터 구조/객체/테이블]이 필요합니다. | '그릇'이 구체적으로 어떤 구현체(예: PermissionContainer 클래스 등)를 의미하는지 확인 필요 |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | (유지) | - |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 권한을 판정하는 주체(모듈/함수)와 '적용'의 구체적인 동작(순회, 덮어쓰기, 조기 반환 등) | 구체화 필요 | [권한 판정 모듈]은 '사용자 직접 거부 $\rightarrow$ 사용자 직접 허용 $\rightarrow$ 역할 거부 $\rightarrow$ 역할 허용' 순으로 권한을 확인하며, 거부 설정이 발견되면 즉시 거부로 판정합니다. | 1. 판정을 수행하는 주체가 무엇인지 확인 필요<br>2. '거부를 우선한다'는 것이 우선순위 리스트의 상단에 있다는 뜻인지, 동일 순위 내에서 거부를 우선한다는 뜻인지 확인 필요 |
