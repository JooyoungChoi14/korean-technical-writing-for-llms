## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 은유적 표현 “그릇”이 실제 요구되는 데이터 구조를 가리키는지 불명확함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 구체적으로 어떤 형태(데이터 구조, 객체, 파일 등)인지 | 구체화 필요 | 권한을 저장할 **데이터 구조(예: 토큰 객체, DB 테이블, 메모리 캐시)**가 필요합니다. | 사용 중인 시스템에서 권한을 보관하는 구현체가 무엇인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 적용 순서와 “거부를 우선”이 구체적으로 어떤 로직을 의미하는지(예: 첫 번째 거부 발견 시 즉시 종료) | 구체화 필요 | 권한을 평가할 때는 **① 사용자 직접 거부 → ② 사용자 직접 허용 → ③ 역할 거부 → ④ 역할 허용** 순으로 검사하고, 거부가 발견되면 허용보다 우선하여 최종 결과를 **거부**로 결정합니다. | 적용 순서가 실제 구현과 일치하는지, “거부 우선”이 언제(전체 평가 중) 적용되는지 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. |  | 통과 |  |  |

- 2번 문장은 정보가 충분히 제공되어 **통과**로 판단됩니다.
