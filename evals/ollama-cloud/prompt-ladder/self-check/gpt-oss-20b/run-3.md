## 요약
- 구체화 필요 2건  
- 의미 확인 필요 0건  
- 가장 큰 독해 부담: “권한을 담아낼 그릇이 필요합니다.” (비유적 표현)  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 의미하는 것은 “저장 컨테이너”이며, “담아낼”은 “저장한다”는 동작 | 구체화 필요 | 권한을 저장할 컨테이너가 필요합니다. | 해당 시스템이 권한을 저장하기 위해 별도의 컨테이너(예: 데이터베이스 테이블, 메모리 구조)를 사용한다는 사실 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 누가(시스템) 이 규칙을 적용하는지, “순으로 적용”이 “우선순위”를 의미하는지 | 구체화 필요 | 시스템은 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용하며, 거부가 우선됩니다. | 시스템이 이 순서대로 정책을 평가하고, 거부가 허용보다 높은 우선순위를 갖는다는 구현 세부사항 |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 없음 | 통과 | — | — |

> **문장 2**는 대상, 동작, 조건, 결과가 명확히 제시되어 있어 별도 지적이 필요 없습니다.
