## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 3번 문장에서 적용 순서와 "거부를 우선"의 관계가 확정되지 않음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 실제로 무엇인지 — 데이터 구조, 저장 필드, 클래스, 테이블 중 어느 것인지 | 구체화 필요 | 권한 정보를 저장할 데이터 구조가 필요합니다. | 실제 구현 대상이 무엇인지 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | ① "순으로 적용"이 첫 일치 우선(first-match-wins)인지 ② "거부를 우선"이 같은 출처 내에서 거부가 허용보다 앞선다는 뜻인지, 아니면 전체 정책이 거부 기본값(deny-by-default)인지 ③ 사용자 허용이 역할 거부보다 앞서므로 거부 우선과 모순되지 않는지 | 의미 확인 필요 | 권한 판정은 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 평가하며, 같은 출처에서는 거부가 허용보다 우선합니다. | 평가 모델이 첫 일치 우선인지, "거부를 우선"의 정확한 범위 |

## 통과
- **문장 2:** 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. — 주체(임시 권한), 동작(저장·비교·확인), 조건(각 요청에서), 결과(유효성 확인)가 문장 자체로 충분히 드러납니다.
