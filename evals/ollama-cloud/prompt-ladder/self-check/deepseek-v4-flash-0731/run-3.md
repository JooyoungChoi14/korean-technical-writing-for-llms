## 요약
- 구체화 필요 1건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 비유적 표현("그릇")이 실제 구현 대상을 가림.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 구체적으로 무엇인지(자료 구조, DB 테이블, 변수, 클래스 등), "담아낸다"가 저장인지 전달인지 | 구체화 필요 | 권한을 저장할 자료 구조(또는 필드)가 필요합니다. | 권한을 보관할 대상이 데이터베이스 테이블인지, 메모리 객체인지, 설정 파일인지 |

## 문제없는 문장
- **문장 2**: 통과. 대상(임시 권한), 동작(저장, 비교, 확인), 조건(각 요청)이 모두 명시되어 있습니다. "임시 권한"이 주어로 의인화되었지만, 기술 문서에서 흔한 표현이며 동작이 구체적이어서 독해 부담이 없습니다.
- **문장 3**: 통과. 적용 순서(사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용)와 최종 우선순위(거부 우선)가 명확하게 제시되어 있습니다. 각 항목이 명사형이지만, "적용"이라는 동작과 "거부 우선"이라는 결과 규칙이 함께 있어 의미가 확정됩니다.
