## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 '그릇' 비유가 실제 저장 대상을 가린다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 대상(자료 구조, 필드, 테이블 등)과 그 대상에 수행할 동작 | 구체화 필요 | 권한을 저장할 자료 구조가 필요합니다. | 권한을 담는 대상이 자료 구조인지, DB 테이블인지, 필드인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 의미(평가 순서인지 우선순위인지)와 주체(어느 모듈이 적용하는지) | 구체화 필요 | 권한 검사는 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 평가하며 거부를 허용보다 우선합니다. | 순서가 '먼저 일치하는 규칙 적용'인지, 우선순위 점수 방식인지 |

## 통과
- 2번: 대상(임시 권한), 동작(만료 시각 저장, 현재 시각 비교), 조건(각 요청에서)이 모두 문장 안에 드러나 있어 문제가 없습니다.
