## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 3번 문장의 적용 순서와 ‘거부 우선’ 원칙이 충돌할 수 있어 정확한 권한 판정 규칙을 복원하기 어렵습니다.

문제 없음: 2번 문장은 통과로 판정했습니다. 임시 권한의 만료 시각 저장과 요청 시 비교 동작이 문장에서 충분히 드러납니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | ‘그릇’이 실제로 가리키는 구현 대상과 담을 권한의 속성 | 구체화 필요 | 권한 정보를 표현하고 저장할 구조가 필요합니다. | 실제 구현 대상이 자료 구조, 모델, 테이블, API 중 무엇인지, 어떤 권한 속성을 담는지 |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 적용 순서가 ‘첫 번째 일치 우선’인지, ‘거부 규칙 전체 우선’인지, 충돌 시 어느 규칙이 이기는지 | 의미 확인 필요 | 권한 판정은 거부 규칙을 허용 규칙보다 먼저 평가합니다. 예: 사용자 직접 거부 → 역할 거부 → 사용자 직접 허용 → 역할 허용. | 적용 순서의 의미, 사용자 직접 허용과 역할 거부가 충돌할 때의 우선순위, ‘거부 우선’이 모든 단계에 적용되는지 여부 |
