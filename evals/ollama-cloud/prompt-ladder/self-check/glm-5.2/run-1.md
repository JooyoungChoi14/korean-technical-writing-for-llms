## 요약
- 구체화 필요 1건, 의미 확인 필요 0건
- 가장 큰 독해 부담: "그릇"이라는 비유가 실제로 어떤 데이터 구조·객체·필드를 만들어야 하는지 가려, 독자가 구현 대상을 문맥에서 재구성해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장할 구체적인 대상(변수·객체·테이블·컬렉션)과 그 대상이 수행하는 역할 | 구체화 필요 | 권한 정보를 저장할 데이터 구조(또는 객체)가 필요합니다. | "그릇"이 가리키는 구현체가 변수, 클래스, DB 테이블 중 무엇인지 확인 필요 |

**통과 문장**

- **2번 문장** — 임시 권한의 저장 대상(만료 시각), 비교 시점(각 요청), 비교 대상(현재 시각), 확인 결과(유효성)가 문장 안에 모두 드러나 있어 독자가 추가 추측 없이 동작을 이해할 수 있습니다.
- **3번 문장** — 네 가지 판정 범주의 적용 순서와 최종 우선 규칙(거부 우선)이 명시되어 있어 대상·동작·조건·결과가 문장 자체로 충분합니다.
