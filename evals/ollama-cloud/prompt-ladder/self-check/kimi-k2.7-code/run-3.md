## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 `그릇` 비유가 실제 구현 대상(클래스, 테이블, 필드 등)을 가림.

## 문제 있는 문장

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | `그릇`이 클래스, 테이블, 필드, 데이터 구조 중 무엇인지. | 구체화 필요 | 권한을 저장할 데이터 구조(또는 클래스/필드)가 필요합니다. | 문맥에서 `그릇`이 가리키는 구현체. |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 이 우선순위를 적용하는 주체(권한 판정 모듈, 정책 엔진 등)와 `적용`의 구체적 동작. | 구체화 필요 | 권한을 판정할 때는 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 검사하며, 거부 결정을 우선 적용합니다. | `적용` 주체와 평가 시점. |

## 문제 없는 문장
- 2. 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. (통과)
