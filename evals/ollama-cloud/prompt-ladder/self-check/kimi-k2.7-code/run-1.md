## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 “그릇”이 지칭하는 구현체와 문장 2의 시각 비교·유효성 확인 주체

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 클래스, 테이블, 모델, 필드 등 구체적으로 무엇인지 | 구체화 필요 | 권한을 저장할 [데이터 구조/모델/객체]가 필요합니다. | “그릇”이 지칭하는 구현체(클래스, 테이블, 모델, 필드 등)는 무엇입니까? |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 만료 시각을 비교하고 유효성을 확인하는 주체(모듈, 서비스, 미들웨어 등) | 구체화 필요 | 임시 권한에 만료 시각을 저장하고, [주체]가 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 시각 비교와 유효성 확인을 수행하는 모듈은 무엇입니까? |
