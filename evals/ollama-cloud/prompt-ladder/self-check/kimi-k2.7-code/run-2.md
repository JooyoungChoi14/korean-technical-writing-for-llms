## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 “그릇” 비유로 인해 독자가 구현체를 추측해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 클래스, 필드, 테이블, 데이터 구조 중 무엇인지 | 구체화 필요 | 권한을 저장할 [데이터 구조/필드/클래스]가 필요합니다. | “그릇”이 가리키는 구현체 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 비교와 확인을 수행하는 주체가 임시 권한 객체인지 별도 모듈인지 | 구체화 필요 | 임시 권한은 만료 시각을 저장합니다. [검증 주체]는 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 유효성 검증을 수행하는 주체 |

## 문제가 없는 문장
- **3. 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.** → 통과. 우선순위 순서와 거부 우선 원칙이 문장 자체로 명확합니다.
