## 요약
- 구체화 필요 2건, 의미 확인 필요 0건  
- 가장 큰 독해 부담: 메타 표현(그릇)과 압축된 명사 나열  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|--------------------------|------|--------|-------------|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 구체적으로 무엇을 가리키는가 (변수, 저장소, 토큰 등)와 해당 객체에 권한을 어떻게 보관/관리하는가 | 구체화 필요 | 권한을 저장할 변수나 저장소가 필요합니다. | 구현에서 권한을 실제로 보관하는 메커니즘(예: 세션 객체, 토큰 컨테이너)은 무엇인가? |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 누가(무엇이) 이 규칙들을 적용하는지, 무엇이 적용되는지(접근 결정 절차), 그리고 “거부를 우선”한다는 구체적인 동작(deny가 allow보다 먼저 평가됨) | 구체화 필요 | 정책 엔진은 사용자 직접 거부를 먼저 적용하고, 다음으로 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 평가하여, deny가 allow보다 우선시됩니다. | 인증/인가 컴포넌트가 tatsächlich 이 순서대로 규칙을 평가하고, deny가 allow보다 높은 우선순위를 가지는지 확인 |

**통과된 문장**  
- 문장 2: “임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.” – 주체, 동작, 조건, 결과가 명시되어 있어 추가 설명 없이 이해 가능.
