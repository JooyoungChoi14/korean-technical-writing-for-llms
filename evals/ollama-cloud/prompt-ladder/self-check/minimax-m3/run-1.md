## 요약
- 구체화 필요 1건 (1번), 의미 확인 필요 1건 (3번)
- 가장 큰 독해 부담: 1번은 비유("그릇")가 실제 자료구조·속성 정보를 가리고, 3번은 "순으로 적용"과 "거부 우선"의 관계가 원문만으로 확정되지 않음

| 위치 | 원문 | 독자가 추론해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 가리키는 구체적 자료구조(클래스, 토큰, 정책 객체 등)와 보관할 속성 목록 | 구체화 필요 | 권한 정보를 보관할 자료구조가 필요합니다. 보관할 항목(예: subject, scope, 만료 시각 등)은 별도로 정의합니다. | 어떤 자료구조를 도입할 계획인가? 보관할 속성의 확정 목록은 무엇인가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | (a) 평가 알고리즘이 first-match-wins인지, (b) "거부 우선"이 "순서"와 같은 의미인지 deny-override처럼 별개의 override 규칙인지 | 의미 확인 필요 | (A안·순서가 곧 우선순위) 다음 순서로 평가해 먼저 매치된 규칙의 결과를 채택합니다. ① 사용자 직접 거부 → ② 사용자 직접 허용 → ③ 역할 거부 → ④ 역할 허용. (B안·deny-override) 네 항목을 모두 평가한 뒤, 그중 하나라도 거부가 있으면 최종 결과를 거부로 결정합니다. | 평가 알고리즘은 first-match-wins인가, deny-override인가? 네 항목은 정책, 효과, 평가 단계 중 무엇을 가리키는가? |

## 통과한 문장
