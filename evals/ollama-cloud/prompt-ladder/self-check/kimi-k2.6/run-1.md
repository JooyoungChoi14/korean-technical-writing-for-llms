## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번의 ‘그릇’ 비유로 인해 실제 도입 대상(데이터 구조·객체)을 추측해야 함. 3번의 ‘적용’과 ‘우선’으로 인해 규칙 평가 순서와 충돌 시 결과가 명확하지 않음.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | ‘그릇’이 구체적으로 어떤 데이터 구조나 객체를 가리키는지, 어떤 동작(저장·전달·변환)을 수행하는지 | 구체화 필요 | 권한을 저장할 속성(또는 객체·필드)이 필요합니다. | ‘그릇’이 클래스, 필드, 변수, 토큰 중 무엇을 지칭하는가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | ‘적용’의 주체와 대상, ‘거부를 우선한다’는 평가 순서인지 충돌 시 결과인지 | 구체화 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 규칙을 평가하며, 동일 권한에 대해 거부와 허용이 충돌하면 거부를 적용합니다. | 이 순서가 평가 우선순위인지, 아니면 규칙 적용(override) 우선순위인지 |

## 문제가 없는 문장
- **2번**: 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.  
  → 대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청)이 명확하게 드러나 있습니다.
