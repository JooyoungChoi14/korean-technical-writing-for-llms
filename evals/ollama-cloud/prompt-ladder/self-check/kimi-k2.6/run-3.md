## 요약
- 구체화 필요 2건, 의미 확인 필요 0건(원문 뜻은 유추 가능하나 정보가 가려짐)
- 가장 큰 독해 부담: 문장 3의 주어 누락과 동작 압축으로 인해 평가 순서와 우선순위 규칙을 재구성해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 가리키는 실제 구성 요소(변수, 객체, 필드, 데이터 구조 등) | 구체화 필요 | 권한을 저장할 구성 요소가 필요합니다. | "그릇"이 구체적으로 어떤 프로그래밍 요소(객체, 필드, 변수 등)를 의미하는지. |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 1) 이 순서를 적용하는 주체(시스템, 모듈 등) 2) "적용"의 대상과 정확한 동작(규칙 평가? 우선순위 적용?) 3) "거부를 우선한다"의 구체적 의미(거부 결정이 허용보다 우선순위가 높음? 평가 순서상 거부가 먼저?) | 구체화 필요 | 권한 평가는 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 규칙을 적용하며, 거부 결정을 허용보다 우선시합니다. | 1) 규칙을 평가하는 주체 2) "적용"의 정확한 의미(평가? 해석?) 3) "거부를 우선"의 의미(우선순위? 순서?) |

## 문제 없는 문장
- **문장 2**: 대상(임시 권한)과 동작(저장, 비교, 확인)이 명확하여 통과. 다만 "임시 권한"이 직접 동작하는 주어로 쓰인 점은 의인화이나, 객체지향 문맥에서 허용되는 표현입니다.
