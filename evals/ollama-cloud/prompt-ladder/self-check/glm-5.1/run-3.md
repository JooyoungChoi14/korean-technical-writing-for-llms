## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: '그릇'이라는 비유가 실제 자료 구조와 동작(저장/할당)을 가리고, '임시 권한'이라는 데이터가 동작의 주체로 서술되어 실제 수행 주체를 추측해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 어떤 자료 구조나 객체인지, '담아낸다'가 저장인지 할당인지 | 구체화 필요 | 권한을 저장할 객체가 필요합니다. | '그릇'이 가리키는 구체적인 자료 구조나 타입 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 만료 시각을 저장하고 비교하는 주체(모듈이나 시스템) | 구체화 필요 | 인가 모듈은 임시 권한의 만료 시각을 저장하고, 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 만료 시각을 저장하고 비교하는 주체는 무엇인가? |

**통과 문장**
- 3번 문장: 대상(권한 규칙)과 동작(우선순위 적용, 거부 우선)이 문장 자체로 충분히 전달되므로 통과입니다.
