## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 1의 비유가 실제 구현 대상을 감춘다.

## 상세 감사

| # | 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|---|
| 1 | 문장 전체 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 무엇인가? (스키마, 테이블, 속성, 메모리 구조?) 권한을 담아낸 뒤 어디에 사용하는가? | 구체화 필요 | `임시 권한 정보를 저장할 테이블이 필요합니다.` 또는 상황에 맞는 구체적 대상 | 권한을 실제로 저장할 저장소 형태(테이블, 캐시, JWT 등)가 무엇인지 |
| 2 | 문장 전체 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | — | 통과 | — | — |
| 3 | 문장 전체 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용한다"는 구체적으로 어떤 시점에 어떤 연산을 하는가? (예: DB 조회 시 ORDER BY, 분기 로직에서 if/else 순서, 정책 객체 평가 순서?) | 의미 확인 필요 | `요청 시 권한 체크 순서를 '사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용'으로 정하고, 먼저 매칭된 결과를 반환합니다.` | 적용 순서를 실제로 구현하는 코드 위치를 확인할 수 있는가? |
