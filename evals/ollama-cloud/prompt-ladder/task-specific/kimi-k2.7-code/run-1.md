## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 1번 문장의 "그릇" 비유로 인해 실제 구현 대상(자료 구조, 클래스, 테이블 등)을 추측해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 클래스, 테이블, 모델, 필드, 자료 구조 중 무엇인지 | 구체화 필요 | 권한을 저장할 {자료 구조/클래스/테이블}이 필요합니다. | "그릇"의 구체적 구현체 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | ① "순으로 적용"이 평가 순서인지 우선순위인지, ② "거부를 우선"이 모든 거부가 모든 허용보다 우선인지, 아니면 같은 주체 내에서만 우선인지 | 의미 확인 필요 | (원문만으로 정확한 의미를 확정할 수 없어 수정안을 제시하지 않습니다.) | ① 순서의 정확한 의미, ② 사용자 직접 허용과 역할 거부가 충돌할 때 최종 결과 |

## 문제 없는 문장
- **2번 문장**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.` → **통과**  
  (주체가 모듈/시스템임은 문맥상 자연스럽게 이해할 수 있으며, 동작과 조건이 명확합니다.)

## 의미 확인 필요 상세
- **3번 문장**: "사용자 직접 허용 + 역할 거부" 조합에서 최종 결과가 거부인지 허용인지 원문만으로 확정되지 않습니다.  
  질문: 이 규칙에서 사용자 직접 설정과 역할 설정이 충돌할 때, 어떤 설정이 우선합니까? 또한 거부가 허용보다 우선하는 것은 전체 범위에서 항상 적용됩니까?
