## 요약
- 구체화 필요 1건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 "그릇"이 가리키는 실제 구성 요소

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 클래스, 테이블, 모델, 필드 등 어떤 구성 요소인지 | 구체화 필요 | 권한을 저장할 {클래스/테이블/모델}이 필요합니다. | "그릇"이 가리키는 구체적인 구현체 |

## 문제 없는 문장
- **문장 2**: 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. → **통과**  
  (대상·동작·조건이 명확하고, "유효성"이 만료 여부 확인으로 충분히 읽힙니다.)
- **문장 3**: 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. → **통과**  
  (우선순위와 거부 우선 원칙이 문장 자체로 분명합니다.)
