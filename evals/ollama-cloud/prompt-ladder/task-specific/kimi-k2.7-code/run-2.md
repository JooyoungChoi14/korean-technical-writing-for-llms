## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 1번 문장의 "그릇"이 가리키는 구현 대상을 독자가 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 클래스, 모델, 테이블, 데이터 구조 중 무엇인지 | 구체화 필요 | 권한을 저장할 [구체적 대상]이 필요합니다. | "그릇"이 가리키는 구현체의 정확한 종류 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 누가 저장·비교·확정하는지, 유효하지 않을 때의 결과는 무엇인지 | 구체화 필요 | 임시 권한의 만료 시각을 저장하고, 각 요청에서 현재 시각과 비교해 만료 여부를 확인합니다. | 저장·비교·확인의 주체(모듈/함수/시스템)와 만료 시의 처리(거부/경고 등) |

## 통과한 문장
- **3번 문장**: 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.  
  → 평가 우선순위와 거부 우선 원칙이 문장 자체로 명확합니다. (사용자 직접 허용 + 역할 거부 조합 시 최종 결과는 거부로 판정됩니다.)
