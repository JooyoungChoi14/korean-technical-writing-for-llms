## 요약
- 의미 확인 필요 2건, 문제 없음 1건
- 가장 큰 독해 부담: 권한 평가 순서와 거부 우선 원칙이 충돌합니다.

문제 없는 문장: 2번 — 임시 권한의 만료 시각 저장·비교 동작이 명확합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | 권한을 어떤 형태로 보관하는지, 어떤 동작을 지원해야 하는지 | 의미 확인 필요 | 권한을 보관할 자료 구조(또는 모델)가 필요합니다. | 권한을 담는 구현체가 자료 구조, 모델, 테이블 중 무엇인지, 저장 외에 조회·비교 동작도 필요한지 |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 실제 평가 순서와 거부 우선 규칙의 관계, 직접 허용과 역할 거부가 충돌할 때의 결과 | 의미 확인 필요 | 거부를 우선 적용합니다. 같은 수준에서는 사용자 직접 규칙을 역할 규칙보다 먼저 평가합니다. 예: 사용자 직접 거부 → 역할 거부 → 사용자 직접 허용 → 역할 허용. | 사용자 직접 허용과 역할 거부가 동시에 적용될 때 최종 결과가 거부인지 허용인지, ‘순으로 적용’이 첫 일치 우선인지 나중 적용 우선인지 |
