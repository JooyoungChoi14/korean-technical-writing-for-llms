## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 권한 평가 순서와 “거부 우선” 원칙이 충돌할 수 있음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장할 실제 구현 형태와 저장 동작 | 구체화 필요 | 권한을 저장할 자료 구조가 필요합니다. | 자료 구조의 실제 형태(테이블, 모델, 정책 객체 등) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 직접 허용과 역할 거부가 충돌할 때 어느 쪽이 최종 결과가 되는지, 적용 방식이 첫 일치 우선인지 전체 평가인지 | 의미 확인 필요 | 거부를 전역으로 우선한다면: 사용자 직접 거부 → 역할 거부 → 사용자 직접 허용 → 역할 허용. 직접 허용이 역할 거부보다 우선한다면: 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용. | 사용자 직접 허용 + 역할 거부 조합의 최종 결과, 적용 방식(첫 일치 우선/전체 평가) |

문제 없는 문장:  
- 2번: 임시 권한의 만료 시각 저장·비교 동작이 명확합니다.
