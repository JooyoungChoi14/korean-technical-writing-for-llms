## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 1번은 비유(`그릇`)가 자료구조 추가 동작을 가리고, 3번은 "적용"의 방식과 "거부 우선"의 범위가 모호해 우선순위 결과를 확정할 수 없음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 종류의 권한(파일·리소스·액션 등)을 어떤 자료구조/메커니즘으로 보관하는지 | 구체화 필요 | 권한 정보를 보관할 구조가 필요합니다. | 다룰 권한의 범위, 새로 도입할 자료구조/모델의 이름 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"이 순차 평가인지 누적 후 우선순위 종합인지, 사용자 직접 허용과 역할 거부가 동시에 성립할 때 최종 결과 | 의미 확인 필요 | 권한 결정 시 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 평가하고, 거부 결정은 허용 결정보다 우선합니다. | (1) 사용자 직접 허용과 역할 거부가 동시에 성립하는 경우의 최종 결과 (2) "거부 우선"이 사용자/역할 같은 수준에만 적용되는지, 수준을 가로질러도 적용되는지 |

## 통과
- **2번** "임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다." — 주체(임시 권한), 동작(저장·비교·확인), 조건(각 요청), 결과(유효성)가 모두 드러나 문장 자체로 충분합니다.
