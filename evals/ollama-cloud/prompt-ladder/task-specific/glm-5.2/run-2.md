## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 권한 규칙에서 '나열된 순서 적용'과 '거부 우선' 원칙이 충돌할 때 최종 결과가 무엇인지 문장만으로 확정되지 않습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 코드 요소(자료 구조, 필드, 객체 등) | 구체화 필요 | 권한 정보를 저장할 자료 구조(또는 필드)가 필요합니다. | '그릇'이 구체적으로 어떤 코드 요소(예: 컬렉션, 커스텀 타입)를 의미하는가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '사용자 직접 허용'과 '역할 거부'가 동시에 성립할 때 최종 결과 | 의미 확인 필요 | (의미 확인 후 수정) | 사용자에게 직접 부여된 허용과 역할에서 부여된 거부가 동시에 성립할 때, 나열된 순서(사용자 직접 허용 우선)를 따르는지, 아니면 '거부 우선' 원칙(역할 거부 우선)을 따르는지? |

## 통과한 문장
- **2.** 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. (통과)
