## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 3번 문장의 적용 순서와 '거부 우선' 원칙 사이의 논리적 충돌

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 구체적으로 무엇을 의미하는지 (데이터 구조, 필드, 테이블, 변수 등) | 구체화 필요 | 권한을 저장할 필드(또는 데이터 구조)가 필요합니다. | 권한을 실제로 저장하는 대상이 데이터베이스 컬럼인지, 메모리 객체인지, 별도 테이블인지 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '순으로 적용'이 '먼저 일치하는 규칙이 최종 결과'인지, '모두 평가 후 거부가 하나라도 있으면 거부'인지. 특히 '사용자 직접 허용'과 '역할 거부'가 동시에 성립할 때 어느 쪽이 이기는지. | 의미 확인 필요 | (거부 우선이 맞다면) "사용자 직접 거부, 역할 거부, 사용자 직접 허용, 역할 허용 순으로 적용합니다." 또는 "거부 규칙을 먼저 평가해 하나라도 거부면 거부로 결정합니다." | '사용자 직접 허용'과 '역할 거부'가 충돌할 때의 최종 결과는 무엇인가? 현재 문장은 순서상 '사용자 직접 허용'이 '역할 거부'보다 먼저이므로 '거부 우선'과 모순됩니다. |

## 통과 문장
- **문장 2**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.` — 대상(임시 권한), 동작(저장, 비교, 확인), 조건(각 요청, 현재 시각)이 모두 명확하게 드러나 있어 문제가 없습니다.
