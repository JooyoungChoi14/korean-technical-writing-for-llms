## 요약
- 구체화 필요 2건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 3의 적용 순서입니다. 나열된 순서가 곧 우선순위라면 사용자 직접 허용이 역할 거부를 이기고, '거부 우선'이 모든 조합에 적용된다면 역할 거부가 이깁니다. 두 읽기가 실제 접근 허용/거부 결과를 정반대로 만드는데, 문장만으로 어느 쪽인지 정할 수 없습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실체(테이블·필드·객체 등)와 '담아낼'의 실제 동작(저장) | 구체화 필요 | 권한 정보를 저장할 구조가 필요합니다. | '그릇'의 실체 — 데이터베이스 테이블, 사용자 레코드의 필드, 코드상 자료 구조 중 무엇인지 |
| 문장 3 (규칙 나열) | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 | 네 명사구가 '사용자에게 직접 부여된 거부/허용 규칙', '역할을 통해 부여된 거부/허용 규칙'이라는 점 | 구체화 필요 | 사용자에게 직접 부여된 거부, 사용자에게 직접 부여된 허용, 역할이 부여한 거부, 역할이 부여한 허용 | '사용자 직접'이 사용자 계정에 직접 연결된 규칙을 뜻하는지 |
