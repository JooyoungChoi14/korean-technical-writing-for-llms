## 요약
- 의미 확인 필요 2건(문장 1, 3), 통과 1건(문장 2)
- 가장 큰 독해 부담: 문장 3 — '순으로 적용'의 평가 규칙과 '거부 우선'이 동시에 성립하는 조합의 최종 결과를 원문만으로 확정할 수 없어, 독자가 조합별로 결과를 시뮬레이션해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 대상(DB 테이블·컬럼, 모델 필드, 클래스 등)과 '담아낼'의 실제 동작(저장·표현 등). 비유가 대상과 동작을 통째로 대신함 | 의미 확인 필요 | 권한을 저장할 [대상 — 예: User 모델 필드 / 별도 권한 테이블]이 필요합니다. | '그릇'에 해당하는 실제 구현 대상은 무엇입니까? |

'거부 우선'이면 거부(③)가 이겨야 하지만, 첫 일치 우선이면 허용(②)이 이기므로 두 규칙이 이 조합에서 충돌합니다. |

## 통과
- **문장 2** — 통과: 대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청에서)이 문장 안에 드러나 있어 독자가 재구성 없이 읽을 수 있습니다.

- 문장 3의 수정안은 예시이며, '확인할 사실'의 답에 따라 "처음 일치 우선"과 "거부 항상 우선" 중 하나로 확정해야 합니다. 원문만으로는 어느 쪽인지 판정할 수 없어 두 해석을 모두 열어 두었습니다.
