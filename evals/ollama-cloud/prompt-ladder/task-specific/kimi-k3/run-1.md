## 요약

- 구체화 필요 1건(문장 1), 의미 확인 필요 1건(문장 3), 통과 1건(문장 2)
- 가장 큰 독해 부담: 문장 3 — "적용 순서"와 "거부 우선"이 충돌하는 조합(사용자 직접 허용 + 역할 거부)의 최종 결과를 원문만으로 확정할 수 없어, 독자가 권한 규칙을 반대로 구현할 위험이 있습니다.

## 통과 문장

- **문장 2 (통과):** 대상(만료 시각), 동작(저장·비교·확인), 조건(각 요청)이 문장 안에 있어 독자가 복원할 정보가 없습니다. 저장·비교의 주체(시스템)가 생략되어 있으나 문맥 없이도 통상적으로 읽히므로 지적하지 않았습니다.
