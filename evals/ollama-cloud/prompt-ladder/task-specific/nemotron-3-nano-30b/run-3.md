## 요약
- 의미 확인 필요 2건, 구체화 필요 0건  
- 가장 큰 독해 부담: “그릇”이 무엇인지, 거부 우선 순위가 실제 적용되는지

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|--------------------------|------|--------|--------------|
| 1 | 권한을 담아낼 **그릇이 필요합니다.** | “그릇”이 어떤 컨테이너·객체·구조이며, 권한을 저장·전달하려는 목적은 무엇인지 | 의미 확인 필요 | 권한을 **저장할 객체가 필요합니다.** | 해당 객체가 데이터베이스 테이블, 메모리 구조, 설정 파일 등 어떤 형태인지, 권한을 담는 범위(예: 사용자 권한, 시스템 권한) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 **거부를 우선**합니다. | “거부를 우선”이라는 규칙이 네 항목 중 어느 단계에서 먼저 실행되는지, 거부와 허용의 구체적 로직은 무엇인지 | 구체화 필요 | 사용자 직접 거부 > 사용자 직접 허용 > 역할 거부 > 역할 허용 순으로 적용하며, **거부 동작을 가장 먼저 수행**합니다. | 거부 우선 순위가 실제 정책 구현에 반영되는지, 이 순서가 다른 권한 처리 로직과 충돌하지 않는지 |

*문제 없는 문장(2)는 별도로 표시하지 않습니다.*
