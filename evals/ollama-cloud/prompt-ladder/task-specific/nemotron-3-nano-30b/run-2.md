**요약**  
1. ‘그릇’에 해당하는 객체가 무엇인지, 3. 거부·허용 순서와 적용 대상이 명시되지 않아 독자가 추가 정보를 추론해야 함.  
2. 통과  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 **그릇이 필요합니다.** | ‘그릇’이 실제 어떤 데이터 구조·객체·필드인지, 그 구조의 인터페이스는? | 의미 확인 필요 | 권한을 저장할 객체(예: `PermissionStore` 또는 `PermissionBag`)가 필요합니다. | 해당 객체의 타입, 필드·메서드 정의가 코드베이스에 존재하는지 확인 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 **거부를 우선합니다.** | ‘거부를 우선합니다’가 거부와 허용 중 어느 것을 우선시하는지, 이 순서가 어느 단계(인증·인가 등)에서 적용되는지? | 구체화 필요 | 사용자 직접 거부 > 사용자 직접 허용 > 역할 거부 > 역할 허용 순으로 적용하며, 거부 동작이 최종 결정을 내립니다. | 거부·허용 로직이 어느 단계에서 실행되는지, 정책에 명시된 우선순위가 있는지 확인 |
