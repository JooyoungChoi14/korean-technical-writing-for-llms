## 요약
- 구체화 필요 0건, 의미 확인 필요 2건, 통과 1건
- 가장 큰 독해 부담: 3번 — 명시된 적용 순서와 "거부를 우선합니다"라는 요약이 특정 조합에서 서로 충돌하여, 독자가 실제 권한 정책을 복원할 수 없습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'의 실체(자료 구조, 저장소, 구성 요소 중 무엇인지), '담아낸다'가 가리키는 실제 동작(저장인지 정의·보관인지) | 의미 확인 필요 | 권한 정보를 저장할 자료 구조가 필요합니다. `[확인 필요]` — '자료 구조'는 원문에 없는 추정이므로 실체 확인 후 확정 | '그릇'에 해당하는 실제 대상은 무엇입니까? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 사용자 직접 허용과 역할 거부가 동시에 성립할 때의 최종 결과, 규칙 일치 시 나머지 규칙 평가를 중단하는지 여부 | 의미 확인 필요 | 순서가 기준이라면: "사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 평가해 처음 일치하는 규칙을 적용합니다. 같은 수준 안에서는 거부를 허용보다 먼저 적용합니다." / 거부 우선이 기준이라면: "사용자 직접 거부, 역할 거부, 사용자 직접 허용, 역할 허용 순으로 적용합니다." | 사용자에게 직접 부여된 허용과 역할에서 부여된 거부가 동시에 성립하면 최종 결과는 무엇입니까? |

3번 상세: 명시된 순서대로면 사용자 직접 허용(2순위)이 역할 거부(3순위)보다 먼저 적용되어 허용이 이기고, 이 경우 "거부를 우선합니다"는 같은 수준 안에서만 참이 됩니다. 반대로 거부가 항상 우선하는 정책이라면 나열 순서(역할 거부가 사용자 직접 허용 뒤에 있음)가 틀린 것입니다. 원문만으로는 어느 쪽이 의도인지 결정할 수 없어 수정안을 두 가지로 조건부로 제시했습니다.

## 통과
- 2번: 대상(임시 권한), 동작(만료 시각 저장, 요청마다 현재 시각과 비교해 유효성 확인), 조건(각 요청)이 문장 안에 모두 드러나 있어 독자가 별도로 복원할 정보가 없습니다.
