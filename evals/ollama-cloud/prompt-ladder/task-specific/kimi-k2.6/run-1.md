## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 3의 규칙 충돌 해결 방식(나열 순서와 '거부 우선' 원칙이 어떻게 결합하는지 불명확)

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 지칭하는 구체적인 프로그래밍 요소(변수, 객체, 필드, 테이블 등) | 구체화 필요 | 권한을 저장할 **[확인 필요]**가 필요합니다. | '그릇'이 변수, 객체, 필드, 테이블 중 무엇을 가리키는지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 대상(어떤 결정 로직인지)과 방식, 나열한 순서가 평가 우선순위인지, '거부를 우선'이 이 순서와 어떻게 상호작용하는지 | 의미 확인 필요 | (원문 의미 확정 후 재작성) | 1) 이 순서가 충돌 시 평가 우선순위인지<br>2) 사용자 직접 허용과 역할 거부가 동시에 존재할 때 최종 결과는 무엇인지 |

## 통과 문장
- **문장 2**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.` → 대상, 동작, 조건, 결과가 명확합니다. (`통과`)
