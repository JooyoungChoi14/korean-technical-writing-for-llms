## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 비유

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 데이터 구조·속성·클래스를 추가하는지, 권한을 담아서 어디에 전달하는지 | 구체화 필요 | "임시 권한을 저장할 구조(예: 테이블·속성)가 필요합니다." | 임시 권한을 실제로 어떤 형태로 저장하는가? (DB 테이블, 캐시, JWT 등) |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 … | — | 통과 | — | — |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'이라는 동작이 구체적으로 무엇인지 (여러 결과를 합산하는 연산, 먼저 읽는 순서, 덮어쓰기 등) | 구체화 필요 | "사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 평가해, 먼저 나온 결과를 뒤에 덮어씁니다." | 평가 결과의 합산 방식이 실제로 순서대로 덮어쓰기인가, 비트 연산인가? |
