## 감사 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 문장 1의 비유가 기술적 대상을 숨김

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 그릇이 무엇인가? DB 테이블, 메모리 구조, 설정 파일? 권한을 담아낸다는 동작의 구체적 의미는? | 구체화 필요 | `권한 정보를 저장할 테이블(또는 구조체)을 정의해야 합니다.` | 프로젝트에서 이 저장소에 해당하는 기존 요소가 있는가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 적용하는 주체는 무엇인가? 이 순서는 어디에 선언되어 있는가? "거부 우선"이 평가 종료 후 최종 결과만 말하는지, 중간에 거부가 발견되면 중단하는지를 명시해야 한다. | 구체화 필요 | `권한 확인 시 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순서로 평가하며, 처음으로 거부가 발견되면 평가를 중단합니다.` | 실제로 조기 중단(early-return)하는지, 전체를 평가한 뒤 거부를 우선하는지? |

**통과:** 문장 2는 동작(저장·비교·확인), 대상(만료 시각·현재 시각·유효성), 조건(각 요청에서)이 모두 드러나므로 판정 통과.
