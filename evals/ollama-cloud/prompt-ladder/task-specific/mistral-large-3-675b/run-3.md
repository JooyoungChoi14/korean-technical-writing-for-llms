## 요약
- 구체화 필요 1건 (`권한을 담아낼 그릇이 필요합니다.`), 나머지 2건은 통과
- 가장 큰 독해 부담: "그릇"이라는 비유가 권한의 저장 방식과 동작을 가림

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 1) 권한을 저장하는 자료 구조 또는 객체 이름<br>2) 저장된 권한을 어떻게 활용하는지 (예: 조회, 검증, 전달) | 구체화 필요 | 권한을 저장하고 조회할 수 있는 구조체가 필요합니다. | 이 구조체의 공식 명칭 또는 코드 내 식별자가 있습니까? |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | - | - |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | - | 통과 | - | - |

---
**통과 문장 설명**
- **2번**: "임시 권한"이라는 대상과 "저장", "비교", "확인"이라는 동작이 명확히 드러나며, 조건(만료 시각)과 결과(유효성 검증)도 포함되어 있어 독자가 추가 추론 없이 이해할 수 있습니다.
- **3번**: 권한 적용 순서와 거부가 우선한다는 규칙이 구체적으로 기술되어 있어, 독자가 동작 방식을 직접 이해할 수 있습니다.
