## 요약
- 구체화 필요 1건 (`권한을 담아낼 그릇이 필요합니다.`), 나머지 2건은 통과

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 1) 어떤 대상이 권한을 저장하는가?<br>2) "그릇"이 구체적으로 어떤 자료 구조나 엔티티를 가리키는가?<br>3) 권한을 저장하는 목적(예: 검증, 관리, 전달 등)은 무엇인가? | 구체화 필요 | 권한을 저장하고 관리하기 위한 자료 구조(예: `PermissionStore`)가 필요합니다. | "그릇"이 코드에서 실제로 사용되는 용어인지, 아니면 비유적인 표현인지 확인 필요. |

---

### 통과 문장
2. 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.
   → **통과**: 대상(임시 권한), 동작(저장/비교), 조건(요청 시점), 결과(유효성 확인)가 명확함.

3. 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.
   → **통과**: 적용 순서와 우선 규칙이 구체적으로 설명됨. 단, "적용"의 대상이 권한인지 정책인지 명확히 드러나지 않지만, 문맥상 권한 규칙으로 해석 가능.
