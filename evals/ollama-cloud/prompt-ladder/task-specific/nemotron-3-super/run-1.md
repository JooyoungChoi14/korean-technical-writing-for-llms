## 요약
- 구체화 필요 2건, 의미 확인 필요 0건  
- 가장 큰 독해 부담: 비유·압축된 명사열로 인해 주체·동작·조건을 독자가 추측해야 함  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|------------------------|------|--------|-------------|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 구체적으로 어떤 데이터 구조·저장소·메커니즘을 가리키는가? | 구체화 필요 | 권한을 저장할 데이터 구조(예: 권한 테이블·토큰·ACL)가 필요합니다. | 의도한 권한 저장 방식(테이블, 토큰, ACL 등)은 무엇인가? |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 누가 이 순서를 적용하는가(예: 인가 엔진) 및 “거부를 우선”이 구체적으로 어떻게 작동하는가(거부가 허용을覆override하는 규칙인가?) | 구체화 필요 | 인가 엔진은 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순으로 규칙을 평가하며, любой 거부가 매치되면 즉시 거부(허용보다 우선) 처리한다. | 적용 주체(인가 엔진 등)와 “거부가 우선”의 구체적 정책(첫 번째 거부가 발견되면 즉시 종료)は 문서에 명시되어 있는가? |
