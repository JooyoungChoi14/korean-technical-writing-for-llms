## 요약
- 구체화 필요 2건, 의미 확인 필요 0건  
- 가장 큰 독해 부담: “권한을 담아낼 그릇이 필요합니다.”

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 종류의 컨테이너(저장소)인지, 어디에 저장되는지 | 구체화 필요 | 권한을 저장할 수 있는 컨테이너(예: 데이터베이스 테이블, 메모리 캐시 등)가 필요합니다. | 사용되는 저장소 종류와 위치 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | – | 통과 | – | – |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 누가(시스템/정책) 이 규칙을 적용하는지 | 구체화 필요 | 시스템은 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 정책을 적용하며, 거부가 우선됩니다. | 규칙을 적용하는 주체(시스템/정책) |

**문제 없는 문장**  
- 2번 문장은 현재 형태로도 충분히 이해할 수 있습니다.
