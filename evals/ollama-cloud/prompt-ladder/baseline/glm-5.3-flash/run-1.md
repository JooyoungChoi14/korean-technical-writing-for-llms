## 요약
- 구체화 필요 1건(3번), 의미 확인 필요 1건(1번), 통과 1건(2번)
- 가장 큰 독해 부담: 1번 — 필요한 것의 대상과 동작이 모두 비유("그릇", "담아낸다") 뒤에 가려져, 문장만으로는 무엇을 만들어야 하는지 알 수 없습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 가리키는 실제 대상(자료구조, 설정, 권한 객체 등), "담아낸다"의 실제 동작(저장인지 묶어 관리하는 것인지), 어떤 권한을 대상으로 하는지 | 의미 확인 필요 | 권한을 저장할 `[구현 대상]`이 필요합니다. — 대상이 원문으로 확정되지 않아 `[확인 필요]` | "그릇"에 해당하는 실제 구현 대상과, 그 대상이 권한에 대해 수행하는 동작(저장·보관·노출 중 무엇인지) |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"의 해석(처음 일치하는 규칙이 결과를 확정하는지), "거부 우선"의 범위 — 나열 순서대로면 사용자 직접 허용이 역할 거부보다 앞서므로 거부가 항상 우선하지는 않음 | 구체화 필요 | 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순서로 규칙을 확인해, 처음 일치하는 규칙이 허용·거부를 결정합니다. 거부가 허용보다 우선하는 것은 같은 수준(직접 지정/역할) 안에서이며, 사용자 직접 설정은 역할 설정보다 우선합니다. | 처음 일치하는 규칙으로 결과를 확정하는지(뒤 규칙이 다시 덮어쓰지 않는지), 사용자 직접 허용이 역할 거부를 이기는 것이 설계 의도인지 |

## 통과
- 2번: 대상(임시 권한), 저장 값(만료 시각), 시점(각 요청), 방법(현재 시각과 비교), 결과(유효성 확인)가 문장 안에 모두 들어 있어 추가 추론이 필요 없습니다.
