## 요약
- 구체화 필요 1건, 의미 확인 필요 1건, 통과 1건
- 가장 큰 독해 부담: 3번 문장의 적용 순서와 “거부 우선” 규칙이 충돌할 수 있음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장하거나 표현할 실제 대상(자료 구조, 객체, 테이블 등) | 구체화 필요 | 권한 정보를 저장할 자료 구조가 필요합니다. | 저장 대상의 구체적 형태(객체, 테이블, 토큰 등) |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 각 정책의 실제 평가 순서와 거부 우선이 적용되는 범위 | 의미 확인 필요 | 권한 판정은 사용자 직접 거부, 역할 거부, 사용자 직접 허용, 역할 허용 순으로 확인하고, 거부가 하나라도 있으면 거부합니다. (순서는 확인 필요) | 정책 평가 순서와 거부 우선 규칙의 정확한 의미 |

문제 없는 문장: 2번 문장은 통과입니다. 임시 권한의 만료 시각 저장과 요청 시 비교 동작이 명확합니다.
