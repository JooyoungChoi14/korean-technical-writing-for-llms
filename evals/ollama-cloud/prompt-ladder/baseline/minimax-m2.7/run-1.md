## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 1번 문장의 비유("그릇")는 원래 개념을 아는 사람도 실제 동작을 복원해야 한다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇 | '그릇'이 무엇을 저장하는지, 어떤 메커니즘으로 권한을 관리하는지 | 의미 확인 필요 | `권한 정보를 저장할 구조가 필요합니다.` 또는 `권한을 보관할 매체(예: 토큰·세션)가 필요합니다.` | '그릇'이 가리키는 구체적인 구현 요소(세션, 토큰, DB 테이블 등)가 무엇입니까? |
| 3 | 순으로 적용해 거부를 우선합니다 | '적용'이라는 동작이 구체적으로 무엇을 하는지(검사 우선순위 설정, 테이블 갱신 등) | 구체화 필요 | `검사 우선순위를 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순서로 설정하여 거부 규칙을 우선합니다.` | '적용'이 런타임의 검사 순서를 설정하는 동작인지, 아니면 다른 의미(설정 파일 갱신 등)인지 |

**2번 문장은 통과** — "만료 시각"을 저장하고 "비교"하는 동작이 모두 명시되어 있어 독자가 추측할 정보가 없습니다.
