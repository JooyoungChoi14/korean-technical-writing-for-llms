## 요약
- 구체화 필요 1건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 비유

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 실제 기술 구성 요소를 가리키는지, '담아낼'이 저장·전달·위임 중 무엇인지 | 구체화 필요 | 예: "권한 정보를 저장할 별도의 테이블이 필요합니다." / "권한을 위임받을 주체(예: 서비스 계정)가 필요합니다." | 그릇이 지칭하는 실제 대상(테이블, 구조체, 역할 등)과 권한을 담아내는 동작의 구체적 의미 |
| 3번 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 주체·대상·동작, '거부 우선'이 같은 속성 내 우선순위인지 속성 간 비교인지 | 구체화 필요 | 예: "평가 순서는 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용이며, 같은 조건에서 거부는 허용보다 우선합니다." | 동일 조건(사용자 직접 vs 역할)에서 허용과 거부 충돌 시 실제 처리 방식 |

**통과:** 2번 — 임시 권한의 만료 시각 저장 동작과 현재 시각과의 비교를 통한 유효성 확인이 문장 자체로 명확하다.
