## 요약
- 의미 확인 필요 2건(문장 1, 3), 통과 1건(문장 2)
- 가장 큰 독해 부담: 문장 3. 나열된 적용 순서(사용자 허용이 역할 거부보다 앞)와 "거부 우선"이 어떻게 양립하는지 원문만으로 확정할 수 없어, 독자가 평가 규칙 전체를 추측해야 합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 대상(데이터 모델, DB 테이블/컬럼, 토큰 등), '담아내다'의 실제 동작(저장·표현), 필요한 주체와 맥락 | 의미 확인 필요 | [확인 필요] 예: "사용자별 권한을 저장할 데이터 모델이 필요합니다." | '그릇'은 어떤 구성 요소를 가리키는가? |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 네 항목이 규칙 유형이라는 것, '적용'이 평가 순서(첫 일치 규칙 채택)를 뜻하는지, '거부 우선'이 네 유형 전체에 적용되는지 같은 주체(사용자/역할) 안에서만 적용되는지, 일치하는 규칙이 없을 때의 기본 동작 | 의미 확인 필요 | [확인 필요] 예: "권한을 평가할 때 사용자에게 직접 부여된 규칙을 역할 규칙보다 먼저 확인하고, 같은 수준 안에서는 거부 규칙을 허용 규칙보다 먼저 적용합니다." | ① 거부 우선이 전체 수준인가, 같은 주체 수준인가? (전체라면 역할 거부가 사용자 허용보다 앞서야 하므로 나열 순서와 충돌) ② 어떤 규칙도 일치하지 않을 때 허용인가 거부인가? |

## 통과
- **문장 2** — 대상(임시 권한), 동작(만료 시각 저장·현재 시각과 비교), 조건(각 요청), 결과(유효성 확인)가 문장 안에 갖춰져 있어 독자가 별도로 복원할 정보가 없습니다. (선택 사항: 비교·확인의 주체를 "서버는…"으로 명시하면 더 정확하지만, 현재 형태로도 독해에 지장은 없습니다.)
