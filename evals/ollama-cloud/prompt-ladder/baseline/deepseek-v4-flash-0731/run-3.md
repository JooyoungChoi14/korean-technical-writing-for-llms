## 요약
- 구체화 필요 0건, 의미 확인 필요 2건
- 가장 큰 독해 부담: 문장 1의 "그릇"이 실제로 어떤 저장 대상을 가리키는지, 문장 3에서 사용자 직접 허용과 역할 거부가 충돌할 때 어느 쪽이 이기는지 원문만으로 확정할 수 없음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 데이터 구조, 저장소, 변수, 클래스 중 무엇인지 | 의미 확인 필요 | 권한을 저장할 데이터 구조가 필요합니다. | 권한을 보관할 대상이 테이블, 변수, 클래스 중 무엇인지 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 나열된 순서가 우선순위라면 사용자 직접 허용이 역할 거부보다 앞서는데, "거부를 우선"하면 역할 거부가 사용자 직접 허용을 이기는지 | 의미 확인 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 판정하며, 거부 판정은 항상 허용보다 우선합니다. | 사용자 직접 허용과 역할 거부가 충돌할 때의 실제 결과 |

## 통과
- 문장 2: 대상(임시 권한), 동작(저장·비교·확인), 조건(각 요청에서, 현재 시각과)이 모두 문장 안에 드러나 있어 독해 부담이 없습니다.
