## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 3의 "순으로 적용"과 "거부를 우선"이 충돌하여 실제 권한 평가 알고리즘을 추측해야 하는 점

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | "그릇"이 구체적으로 무엇을 의미하는지 (데이터 구조, 저장소, 객체, 테이블 등) | 구체화 필요 | 권한을 저장할 데이터 구조가 필요합니다. | 권한을 저장하는 대상이 메모리 객체인지, DB 테이블인지, 설정 파일인지 |
| 문장 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 각 항목이 규칙인지 행위인지, 그리고 "순으로 적용"과 "거부를 우선"이 어떻게 조화되는지 (마지막 일치가 우선인지, 거부가 항상 우선인지) | 의미 확인 필요 | 사용자가 직접 설정한 거부 규칙, 사용자가 직접 설정한 허용 규칙, 역할에 설정된 거부 규칙, 역할에 설정된 허용 규칙 순서로 평가합니다. 단, 거부 규칙이 하나라도 일치하면 허용 규칙보다 우선합니다. | 실제 평가 순서가 나열된 순서인지, 거부가 항상 우선하는지 (예: 거부가 하나라도 있으면 거부인지) |
