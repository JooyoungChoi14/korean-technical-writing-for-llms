## 요약
- 구체화 필요 1건 (`1. 권한을 담아낼 그릇이 필요합니다.`), 나머지 2건은 통과

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | (1) 어떤 대상이 권한을 저장하는가? (2) 저장된 권한을 어떤 동작에서 사용하는가? (3) '그릇'이 구체적으로 데이터 구조인지, 변수인지, 클래스인지? | 구체화 필요 | 권한을 저장할 데이터 구조(예: `Permission` 클래스 또는 `Map` 객체)가 필요합니다. 이 구조는 각 요청에서 권한을 조회하고 유효성을 검증하는 데 사용됩니다. | '그릇'이 코드에서 실제로 어떤 형태로 구현되는지? |

---
### 통과 문장
2. 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.
   → **통과**: 동작(저장/비교), 대상(임시 권한), 조건(요청 시점)이 명확함.

3. 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.
   → **통과**: 적용 순서와 우선 규칙이 구체적으로 설명됨.
