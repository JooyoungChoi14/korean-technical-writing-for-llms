## 요약
- **구체화 필요 1건** (문장 1): 동작을 비유로만 설명하여 실제 대상이 불분명함.
- **통과 2건** (문장 2, 3): 대상, 동작, 조건이 명확하게 기술됨.

---

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | `권한을 담아낼 그릇이 필요합니다.` | - **대상**: 권한을 저장/관리하는 구체적인 기술 요소 (예: 변수, 데이터 구조, DB 테이블 등)<br>- **동작**: "담아내다"의 실제 구현 방식 (예: 할당, 캐싱, 영속화 등) | 구체화 필요 | `권한을 저장할 데이터 구조(예: 토큰, 세션 객체, DB 레코드)가 필요합니다.` | "그릇"이 프로젝트에서 이미 정의된 용어인지 확인 필요. 정의되지 않았다면 구체적인 기술 요소를 명시해야 함. |

---

### 통과한 문장
- **문장 2**: `임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.`
  → 대상(임시 권한), 동작(저장/비교), 조건(요청 시점)이 명확함.
- **문장 3**: `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
  → 우선순위 규칙과 동작(거부 우선)이 구체적으로 설명됨.
