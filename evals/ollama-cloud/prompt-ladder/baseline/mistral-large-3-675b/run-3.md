## 요약
- **구체화 필요 1건** (문장 1): 동작을 비유로만 설명하여 실제 대상이 불분명함.
- **통과 2건** (문장 2, 3): 대상, 동작, 조건이 명확하게 기술됨.

|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | - "그릇"이 구체적으로 어떤 데이터 구조/객체/필드를 가리키는가?<br>- 권한을 "담는다"는 것이 저장, 전달, 검증 중 어떤 동작을 의미하는가? | 구체화 필요 | 권한을 저장할 데이터 구조(예: `Permission` 객체 또는 `permissionMap` 필드)가 필요합니다. | "그릇"이 프로젝트에서 이미 정의된 용어인지, 아니면 임시 비유인지 확인 필요. |

### 통과한 문장
2. **임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.**
   → 저장 대상(`만료 시각`), 동작(`비교`), 조건(`요청 시점`)이 명확함.
3. **사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.**
   → 적용 순서와 우선 규칙이 구체적으로 기술됨.
