## 요약
- 구체화 필요 1건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 3번 문장에서 권한 적용 순서와 '거부 우선'의 실제 동작 방식이 문맥 없이 모호합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 지칭하는 실제 데이터 구조나 객체 | 구체화 필요 | 권한 정보를 저장할 객체(또는 데이터 구조)가 필요합니다. | 권한을 저장할 구체적인 데이터 구조나 객체의 종류 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용해'의 실제 동작(첫 일치 항목 적용인지, 거부 우선 병합인지)과 나열된 순서와 '거부 우선'의 관계 | 의미 확인 필요 | 권한을 평가할 때 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 규칙을 확인합니다. 이 순서에서 거부 규칙이 먼저 일치하면 접근을 차단합니다. | '적용'의 실제 로직(예: 첫 일치 항목 반환, 거부 우선 병합)과 '거부 우선'의 정확한 조건 |

## 문제 없는 문장
- **2번 문장:** `통과` - 대상(임시 권한)과 동작(만료 시각 저장, 현재 시각 비교, 유효성 확인)이 명확하게 서술되어 독자가 추가적인 맥락 없이도 의미를 파악할 수 있습니다.
