## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장이 비유로 실제 대상(데이터 구조 또는 필드)을 가리고, 3번 문장이 명사 나열과 평가어로 적용 방식을 추측하게 만듦.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장할 구체적인 대상이 데이터 구조인지, 객체 필드인지, 테이블 컬럼인지 | 구체화 필요 | 권한 정보를 저장할 데이터 구조(또는 필드)가 필요합니다. | "그릇"이 가리키는 대상이 메모리 객체인지 DB 스키마인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"이 규칙 평가 순서인지 우선순위인지, "거부를 우선"이 거부 규칙이 하나라도 있으면 최종 거부라는 뜻인지 | 구체화 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 규칙을 이 순서로 평가하며, 평가 결과 중 거부가 하나라도 있으면 최종 결과를 거부로 확정합니다. | "순으로 적용"이 실제로 평가 순서(단락 평가)인지, 단순 우선순위 표기인지 |

**문제 없는 문장**
- 2번: 대상(임시 권한), 동작(만료 시각 저장, 현재 시각 비교), 조건(각 요청), 결과(유효성 확인)가 문장 안에서 충분히 드러납니다. **통과**
