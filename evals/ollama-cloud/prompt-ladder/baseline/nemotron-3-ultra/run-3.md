## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 1번 문장에서 '그릇'이 가리키는 실제 기술 산출물(테이블, 컬럼, 변수, 자료구조 등)이 드러나지 않음

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 무엇인가? (권한 테이블, 컬럼, 변수, 캐시, 별도 스토리지 중 어느 것) | 구체화 필요 | 권한을 저장할 **컬럼(또는 테이블/필드)** 이 필요합니다. | 어떤 스키마 객체에 권한 값을 기록하는지 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | (필수 정보가 문장 안에 모두 있음) | 통과 | — | — |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '거부를 우선합니다'가 앞의 순서 나열을 요약한 것인지, 별도 규칙(예: 동일 순위에서 거부 승)을 추가한 것인지 | 구체화 필요 | 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 **순으로 평가하며, 같은 단계에서 거부가 허용보다 우선합니다.** | 동일 우선순위에서 거부·허용 충돌 시 처리 규칙이 별도로 있는지 |
