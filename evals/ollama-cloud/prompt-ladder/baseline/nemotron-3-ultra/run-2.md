## 요약
- 구체화 필요 2건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 1번 문장의 비유적 표현(`그릇`)이 실제 기술 대상을 완전히 가림

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | `그릇`이 가리키는 실제 자료구조·객체·스토어·컨텍스트 중 무엇인가? | 구체화 필요 | 권한을 저장할 컨테이너(객체/스토어/컨텍스트)가 필요합니다. | 어떤 구체적 타입(예: `PermissionContext`, `TokenStore`, `Map<string, Permission>`)을 의미하는가? |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 주체인 `임시 권한`이 스스로 저장·비교하는가, 아니면 평가기/런타임이 수행하는가? | 의미 확인 필요 | 임시 권한 평가기는 만료 시각을 저장하고, 각 요청마다 현재 시각과 비교해 유효성을 판정합니다. | 실제 평가 주체(컴포넌트/함수/미들웨어) 이름은 무엇인가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | `적용해`의 구체적 연산(마스크 합성, 첫 매칭 승리, deny-overrides 등)이 무엇인가? | 통과 | (문장 자체로 우선순위와 거부 우선 원칙이 명확함) | — |
