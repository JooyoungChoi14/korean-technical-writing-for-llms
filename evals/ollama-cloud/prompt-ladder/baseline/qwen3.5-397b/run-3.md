## 요약
- **구체화 필요 2 건**, 통과 1 건
- **가장 큰 독해 부담:** 1 번 문장의 비유적 표현 (`그릇`) 과 2 번 문장의 주체 생략 (`권한은... 저장하고`) 으로 인해 실제 구현 대상과 동작 주체를 독자가 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 문장 | 권한을 담아낼 그릇이 필요합니다. | `그릇` 이 지칭하는 실제 기술 산출물 (테이블, 객체, 필드 등) | 구체화 필요 | 권한 정책을 정의할 **[객체/테이블/스키마]** 가 필요합니다. | 권한 정보를 저장하거나 표현하는 실제 단위는 무엇입니까? |
| 2 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 데이터를 저장하는 주체 (DB 등) 와 검증 로직을 수행하는 주체 (모듈 등) | 구체화 필요 | 임시 권한 데이터에는 만료 시각이 포함되며, **[시스템/모듈]** 은 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | 만료 시각 저장소와 검증 로직을 담당하는 모듈은 각각 무엇입니까? |

## 통과 문장
- **3 문장:** `사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다.`
    - **판정:** 통과
    - **이유:** 권한 평가 순서와 우선 순위 규칙 (Deny Overrides) 을 명확히 서술하였으며, 기술 문서에서 일반적으로 통용되는 표현입니다. (단, 평가 엔진이 `첫 번째 일치` 방식인지 `전체 평가` 방식인지에 따라 논리적 모순이 발생할 소지는 있으나, 문맥상 의도는 전달됩니다.)
