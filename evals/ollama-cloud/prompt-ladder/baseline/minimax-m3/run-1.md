## 요약
- 구체화 필요 1건 (1번), 의미 확인 필요 1건 (3번)
- 가장 큰 독해 부담: 비유(그릇)와 압축된 우선순위 문장이 각각 실제 대상과 적용 규칙을 가립니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 어떤 종류의 대상(속성, 변수, 컬렉션, 자료구조 등)에 권한을 보관하려는 것인지, 단위(단일 권한인지 권한 목록인지) | 구체화 필요 | 권한을 보관할 속성을 정의해야 합니다. (목록이라면) 권한 집합을 담을 컬렉션이 필요합니다. | 보관 단위가 단일 권한인지 권한 집합인지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | "적용"이 첫 번째 매치 우선인지 규칙을 모두 결합하는지, "거부를 우선"이 같은 출처 내 우선인지 출처를 가리지 않는 절대 우선인지. 나열된 순서는 사용자 직접 허용이 역할 거부보다 앞서므로 "어떤 거부가 모든 허용보다 앞선다"로 읽히면 순서와 충돌함 | 의미 확인 필요 | 사용자 직접 거부 → 사용자 직접 허용 → 역할 거부 → 역할 허용 순서로 첫 번째로 매치되는 규칙을 적용합니다. 같은 출처 안에서는 거부를 허용보다 먼저 확인합니다. | "역할 거부가 사용자 직접 허용을 덮지 않는다"가 의도된 규칙인지, 사용자 규칙에만 "직접"을 붙인 기준이 무엇인지 |

## 통과
- **2번.** "임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다." — 주체(임시 권한), 동작(저장 → 비교), 시점(각 요청에서), 결과(유효성 확인)가 한 문장 안에서 모두 드러나며, 독자가 별도로 추론해야 할 정보가 없습니다.
