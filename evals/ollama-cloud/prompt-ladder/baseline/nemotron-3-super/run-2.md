## 요약
- 구체화 필요 1건, 의미 확인 필요 1건  
- 가장 큰 독해 부담: 메타포와 누락된 명사로 인해 저장 대상과 적용 대상을 추측해야 함  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|--------------------------|------|--------|--------------|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | 권한을 보관할 구체적인 대상(변수, 필드, 테이블 등) | 의미 확인 필요 | 권한을 저장할 **저장소**가 필요합니다. *(구체적 저장소가 무엇인지 확인 필요)* | 권한을 실제로 저장하는 곳은 무엇인가? (예: 메모리 변수, DB 열, 파일 등) |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 적용되는 대상(정책, 규칙, 설정 등) | 구체화 필요 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 **접근 제어 규칙**을 적용하여 거부를 우선시합니다. | 나열된 네 항목이 실제로 적용되는 접근 제어 규칙(또는 정책)인지 확인 |
