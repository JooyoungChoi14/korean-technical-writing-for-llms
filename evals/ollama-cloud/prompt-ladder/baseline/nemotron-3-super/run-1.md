## 요약
- 구체화 필요 2건, 의미 확인 필요 0건  
- 가장 큰 독해 부담: metaphoric expression (“그릇”)과 암시적인 정책 적용 순서

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|--------------------------|------|--------|--------------|
| 문장1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 어떤 구체적인 저장소(변수, 필드, 객체, 테이블 등)를 가리키는지 | 구체화 필요 | 권한을 저장할 변수(또는 필드)가 필요합니다. | 실제 구현에서 권한을 보관하는 데이터 구조는 무엇인가? |
| 문장3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 각 항목이 의미하는 구체적인 규칙 유형(예: 사용자‑별 명시적 deny/allow, 역할‑별 deny/allow)과谁가 이 순서대로 규칙을 적용하는지 | 구체화 필요 | 시스템은 다음과 같은 순서로 접근 제어 규칙을 적용합니다: 1) 사용자별 명시적 거부, 2) 사용자별 명시적 허용, 3) 역할별 거부, 4) 역할별 허용. 이렇게 하면 거부 규칙이 허용 규칙보다 우선 적용됩니다. | “사용자 직접”이 “사용자‑별 명시적”을 뜻하는지, 그리고 적용 주체가 시스템인지 확인 필요 |
