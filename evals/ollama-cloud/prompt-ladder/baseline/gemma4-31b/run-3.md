## 요약
- 구체화 필요 2건, 통과 1건
- 가장 큰 독해 부담: 동작을 대신하는 비유(`그릇`)와 주체가 생략된 명사 나열(`적용해 거부를 우선`)로 인해 실제 구현 대상과 로직의 방향을 추측해야 함.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1번 문장 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 의미하는 실제 기술적 대상(클래스, DB 테이블, 객체, 변수 등)과 그 역할 | 구체화 필요 | 권한 정보를 저장하고 관리할 [객체/테이블/데이터 구조]가 필요합니다. | '그릇'이 구체적으로 어떤 구현체를 의미하는가? |
| 2번 문장 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | - | 통과 | - | - |
| 3번 문장 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 권한을 판정하는 주체(시스템/모듈)와 '적용' 및 '우선'의 구체적인 동작(필터링 순서인지, 최종 값 결정 방식인지) | 구체화 필요 | 권한 판정 시 [판정 모듈]은 '사용자 직접 거부 $\rightarrow$ 사용자 직접 허용 $\rightarrow$ 역할 거부 $\rightarrow$ 역할 허용' 순으로 확인하며, 거부 설정이 있으면 이를 최종 결과로 우선 적용합니다. | 판정 주체가 누구이며, 순차 확인 중 거부를 만났을 때 즉시 종료(Short-circuit)하는 방식인가? |
