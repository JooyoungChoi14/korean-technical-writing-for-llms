## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 문장 1의 비유로 인해 실제 구현 요소를 추측해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 기술 요소(변수, 필드, 객체, 데이터 구조 등) | 구체화 필요 | 권한을 저장할 {필드/속성/객체}가 필요합니다. | 이 맥락에서 '그릇'이 의미하는 구체적인 구현 요소 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 주체와 방식(평가 순서인지, 병합 규칙인지), '거부를 우선'의 구체적 의미 | 구체화 필요 | 권한을 결정할 때 {주체}가 사용자 직접 거부→사용자 직접 허용→역할 거부→역할 허용 순서로 규칙을 평가하며, 거부 규칙을 먼저 적용합니다. | 이 순서가 평가 순서인지, 규칙 병합 시 deny override 규칙인지 |

## 문제 없는 문장
- **문장 2**: 임시 권한의 만료 시각 저장 및 요청 시각과의 비교를 서술하고 있어, 대상과 동작이 명확히 드러나 별도의 추측 없이 이해됩니다.
