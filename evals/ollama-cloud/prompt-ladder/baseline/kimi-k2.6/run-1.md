## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: 1번 문장의 "그릇" 비유로 인해 실제 구현 대상(변수/필드/속성 등)을 추측해야 함

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 프로그래밍 요소(필드, 변수, 속성, 데이터 구조 등) | 구체화 필요 | 권한을 저장할 필드가 필요합니다. | '그릇'이 구체적으로 어떤 요소를 의미하는가? |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | '적용'의 대상과 방식, '순으로'의 정확한 의미(평가 순서?), '거부를 우선'의 실제 메커니즘 | 구체화 필요 | 권한 평가 시 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순서로 규칙을 검사하며, 거부 규칙을 허용보다 먼저 적용합니다. | 이 순서가 평가 우선순위인지, 규칙 적용 순서인지, '거부를 우선'의 구체적 동작 |

## 문제가 없는 문장
- **2번**: 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. (대상과 동작이 명확함)
