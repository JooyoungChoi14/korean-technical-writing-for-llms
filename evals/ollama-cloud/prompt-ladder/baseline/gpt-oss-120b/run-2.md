## 요약
- 구체화 필요 2건, 의미 확인 필요 0건
- 가장 큰 독해 부담: **문장 1**의 은유적 표현, **문장 3**의 동작·대상 불명확

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | “그릇”이 의미하는 구체적 저장소(예: 변수, DB 테이블, 메모리 구조) | 구체화 필요 | 권한을 저장할 **데이터 구조**가 필요합니다. | 어떤 형태의 저장소(객체, 테이블 등)를 사용할지 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | “적용해”가 가리키는 대상(권한 평가 로직) 및 각 단계의 구체적 동작 | 구체화 필요 | 권한을 평가할 때는 다음 순서대로 적용합니다: 1) 사용자가 직접 **거부**한 경우, 2) 사용자가 직접 **허용**한 경우, 3) 역할이 **거부**한 경우, 4) 역할이 **허용**한 경우. 이때 **거부**가 **허용**보다 우선합니다. | 적용 순서와 우선순위가 실제 정책과 일치하는지 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | – | 통과 | – | – |
