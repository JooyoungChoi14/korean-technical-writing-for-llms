**요약**  
- 2개의 문장이 의미·대상을 명확히 하지 못해 추가 설명이 필요합니다.  
- 1개의 문장은 문제 없이 통과합니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|------|------|--------------------------|------|--------|-------------|
| 1 | 권한을 담아낼 **그릇**이 필요합니다. | “그릇”이 어떤 데이터 구조·객체이며, 권한을 **저장**·**전달**하려는 것인지? | 의미·대상 모호 (비유) | 권한을 저장할 **객체**가 필요합니다. | 권한을 저장하려는 대상이 **구조체/맵**인지, 저장 목적이 **전달**인지 확인 |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 **거부를 우선**합니다. | “우선합니다”가 어떤 동작을 **우선**시하는지(거부가 승인보다 먼저 처리되는지), “역할”이 어떤 권한 계층을 의미하는지? | 동작·우선순위 불명확 | 사용자 직접 거부 > 사용자 직접 허용 > 역할 거부 > 역할 허용 순으로 적용하며, **거부**가 가장 높은 우선순위를 가집니다. | 우선순위 규칙이 **구현**된 위치와 **역할**이 정의된 권한 체계가 무엇인지 확인 |
