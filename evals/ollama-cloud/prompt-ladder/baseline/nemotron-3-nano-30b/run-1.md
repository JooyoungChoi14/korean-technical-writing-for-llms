## 요약
- **구체화 필요 2건**  
- **가장 큰 독해 부담:** “그릇” 메타포와 “거부를 우선합니다” 우선순위 명시 부족  

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 1 | 권한을 담아낼 그릇이 필요합니다. | 권한을 저장·전달할 구체적인 객체(예: 구조체, 클래스, 파일 등)가 무엇인지 | **구체화 필요** | 권한을 저장할 객체가 필요합니다. | 해당 객체의 목적(저장, 전달, 검증)과 타입 |
| 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | — | **통과** | — | — |
| 3 | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선합니다. | 거부 동작이 언제, 어떤 경우에 우선 적용되는지, 그리고 거부 대상이 사용자인지 역할인지 | **구체화 필요** | 사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용하며, 거부 동작을 우선 적용합니다. | 거부 우선 여부와 적용 대상(사용자 직접 거부 vs 역할 거부) |
