## 요약
- 구체화 필요 2건, 의미 확인 필요 1건
- 가장 큰 독해 부담: 문장 3의 명사 나열이 권한 판정의 구체적인 조건과 동작을 가리고, 문장 1의 비유가 실제 데이터 구조를 감추고 있습니다.

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
| 문장 1 | 권한을 담아낼 그릇이 필요합니다. | '그릇'이 가리키는 실제 데이터 구조나 변수의 종류 | 구체화 필요 | 권한을 저장할 데이터 구조(또는 변수/객체)가 필요합니다. | 권한을 저장하는 대상이 변수인지, 클래스인지, 데이터베이스 테이블인지 |
| 문장 2 | 임시 권한은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | '임시 권한'이 능동적으로 동작하는 주체(모듈/객체)인지, 아니면 시스템이 처리하는 대상(데이터)인지 | 의미 확인 필요 | (주체가 모듈인 경우) 임시 권한 모듈은 만료 시각을 저장하고 각 요청에서 현재 시각과 비교해 유효성을 확인합니다.<br>(대상이 데이터인 경우) 시스템은 임시 권한에 만료 시각을 저장하고, 각 요청에서 현재 시각과 비교해 유효성을 확인합니다. | '임시 권한'이 동작의 주체인지 대상인지 |
