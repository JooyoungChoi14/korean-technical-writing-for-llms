# 출력 형식

## 검사

```markdown
## 요약
- 구체화 필요 N건, 의미 확인 필요 N건
- 가장 큰 독해 부담: …

| 위치 | 원문 | 독자가 추측해야 하는 정보 | 판정 | 수정안 | 확인할 사실 |
|---|---|---|---|---|---|
```

문제가 없는 문장은 열거하지 않는다. 지적의 근거는 취향이 아니라 누락되거나 모호한 정보로 쓴다.

## 제한 교정

```markdown
## 주요 변경

| Before | After | 이유 |
|---|---|---|

## 수정문
…

## 의미 확인 필요
- …
```

## 문서 작성

독자의 질문 순서에 따라 배경, 결정 또는 목표, 구체적인 동작, 조건과 예외, 다음 행동을 배치한다. 문서 종류가 튜토리얼·절차·참조·설명 중 무엇인지 정하고 서로 다른 목적을 한 섹션에 섞지 않는다.
