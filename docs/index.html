AI가 쓴 한국어 기술 문서는 왜 다시 해석해야 할까

문법 오류가 아니라 독자가 비유를 실제 동작으로 바꾸고, 생략된 주체·조건·결과를 채우는 비용을 찾았습니다. 복잡한 권한·회계·통계 설계 과제로 Claude와 구형 Codex를 블랙박스 테스트하고, 검사 절차를 설치형 스킬로 만들었습니다.

문제 정의·실험 설계·평가·저술: 최주영 (Jooyoung Choi · @JooyoungChoi14)

문장부터 보기독자의 부담실험결과제안설치

먼저, 이 문장들을 읽어 보십시오

두 variant의 parity를 확보한다.
상태를 화면으로 꺼낼 구멍을 연다.
월말 마감 후 역분개 수동 검토 분기.
분석 단위는 ITT로 두고 FDR을 적용한다.

모두 기술 문서에서 나올 법하고 문법적으로 틀렸다고 단정하기도 어렵습니다. 그러나 처음 읽는 사람은 무엇의 수를 같게 하는지, 구멍이 API인지 속성인지, 누가 어떤 조건으로 검토하는지, 두 약어가 시스템에서 무슨 역할을 하는지 먼저 추측해야 합니다.

판정 질문: “한국어처럼 들리는가?”보다 “구현과 판단에 필요한 대상·주체·동작·조건·결과가 문장 안에 있는가?”를 묻습니다.

독자는 문장을 읽은 뒤 다시 조립한다

낱말 인식
variant, parity, 분기 같은 낱말을 알아본다.
결합에서 정지
무엇의 어떤 속성을 말하는지 멈춰 생각한다.
문맥으로 추측
앞뒤 문장과 도메인 지식으로 빠진 정보를 보충한다.
동작으로 재구성
“두 화면의 필드 수를 맞춘다”로 바꾸어 이해한다.
낯선 결합

두 variant의 parity를 확보한다.

두 화면 변형에서 표시되는 필드 수를 같게 맞춘다.

동작을 대신하는 비유

상태를 화면으로 꺼낼 구멍을 연다.

화면이 상태를 읽도록 status 속성을 공개한다.

명사 압축

호출 경유, 변경 불요.

이 모듈은 호출 경로에 포함되지만 이번 작업에서는 변경하지 않는다.

평가가 사실을 대신함

클라이언트만 먼저 배포해도 무해하다.

[확인 필요] 구버전 서버가 새 필드를 무시한다면 기존 기능에는 영향이 없다.

사내 문서 대신 공개 가능한 블랙박스 과제를 만들었다

초기 탐색은 비공개 문서 200개에서 후보 40개를 찾는 방식이었습니다. 그러나 일부 단어를 가려도 시스템과 조직을 추측할 수 있어 공개 근거로 쓰지 않았습니다. 공개판에는 저자가 만든 합성 회귀 사례 20개와, 모델에 실험 목적을 알리지 않고 생성한 새 문서만 넣었습니다.

과제설명해야 할 충돌
종합정보시스템 권한여러 신분, 화면·버튼·필드 권한, 휴직·대리 결재·임시 권한, 허용·거부 우선순위
회계 의사결정선수금·변동 대가·환불·본인/대리인·다중 통화·마감 뒤 수정
통계 의사결정층화 배정·결측·순차 검정·다중 비교·오염·인과 가정·중단 기준

동일한 600자 프롬프트를 Claude Code 2.0.73의 Sonnet과 Codex CLI의 gpt-5.4에 각각 한 번 적용했습니다. 도구와 세션 저장은 사용하지 않았습니다. Gemini 2.5 Pro는 연결된 계정의 제품 라이선스 오류 403으로 실행되지 않아 결과를 만들지 않았습니다.

노골적인 비유보다 더 위험한 문제가 보였다

어려운 용어를 풀라는 요구를 부분적으로만 따랐다

무작위 배정·SUTVA·단조성 가정이 충족되는지 진단 플롯과 통계 검정으로 확인한다. — Claude Sonnet
분석 단위는 기본적으로 배정 기준을 따르는 ITT로 두고 … 가설군별로 FDR 또는 계층적 보정을 적용한다. — Codex gpt-5.4

약어를 없앨 필요는 없습니다. 처음 등장할 때 뜻과 역할을 함께 써야 합니다. 예를 들어 “최초 배정 집단을 기준으로 분석한다(ITT)”처럼 풀 수 있습니다.

문장은 자연스럽지만 근거 없는 정책을 만들었다

월초 5일까지는 소급 허용 … 일 매출 ₩100만 이하 거래는 … 자동 생성한다. — Claude Sonnet

프롬프트에는 5일과 100만 원 기준이 없었습니다. 이는 문체가 아니라 의미와 근거의 문제입니다. `[가정]` 또는 `[확인 필요]`로 표시해야 합니다.

매끄러운 문장 안에 모순이 남았다

사용자 직접 거부, 사용자 직접 허용, 역할 거부, 역할 허용 순으로 적용해 거부를 우선한다. — Codex gpt-5.4

직접 허용이 역할 거부보다 먼저인데 모든 거부가 우선한다고도 읽힙니다. 자연스러움과 의미 보존을 한 점수로 합치면 이런 위험을 놓치기 쉽습니다.

축질문실패 예시
독해 명료성대상과 동작을 문장 안에서 알 수 있는가?약어와 명사 나열만 남음
의미 보존주체·방향·조건·범위·확실성이 유지됐는가?없던 금액·기간·정책을 추가함

표본은 모델별 3건, 각 1회입니다. 모델 우열이나 세대 효과를 추정하지 않습니다. 현재 결과는 하네스의 실패 조건을 찾기 위한 탐색입니다.

작성과 검사를 한 번에 시키지 않는다

1 · 작성사실과 코드 식별자를 보존하고 대상과 동작을 직접 쓴다.
2 · 검사독자가 추측해야 하는 정보만 표시한다.
3 · 제한 교정의미가 확정되는 문제 문장만 고친다.
4 · 의미 검증주체·방향·조건·범위를 수정 전후로 대조한다.

초안 프롬프트에는 긴 금지어 목록을 넣지 않습니다. 금지 표현은 생성 뒤 별도 검사에서 회귀 사례로 사용합니다. 영어 단어와 비유도 실제 대상과 동작이 함께 적혀 있다면 지적하지 않습니다.
